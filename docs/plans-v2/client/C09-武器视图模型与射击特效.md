## 1. 目标

本步骤结束后，第一人称有手臂与武器视图模型（呼吸、行走、后坐、换弹、倒地动作），开火产生枪口火焰与一段从**枪口**指向命中点的曳光，命中 / 击杀 / 爆头三种反馈都可辨认；所有特效走固定容量池，稳态零托管分配。本步修正 v1"曳光与视线共线"的缺陷：曳光起点必须是枪口而不是眼位。

## 5. 冻结契约

冻结的 v1 对照实现：`packages/client/src/render/viewmodelModel.ts` 与 `packages/client/src/render/effects.ts`（只作对照，不修改）。

**(a) 视图模型与挂点**

| 项 | 值 / 定义 |
|---|---|
| `ViewModelFovDeg` | `62` |
| 近/远裁剪 | `0.01m` / `12m`（视图模型独立层，与 C05 冻结的主相机远裁 `300m` 分离） |
| 基准位（相机空间） | `(0.17, −0.19, −0.02)` |
| 枪口挂点（相机空间） | `(0.0, 0.02, 0.58)`；`MuzzleWorld` 与眼位距离 ≥ `0.5m`（硬断言） |
| 渲染状态 | 只受主方向光；不投影、不写深度 |

**(b) 动画与节奏表**

| 项 | 值 / 定义 |
|---|---|
| 换弹时长 | 手枪 `1400ms` / 步枪 `2000ms` / 霰弹 `2600ms`（= `WEAPONS[*].reloadMs`） |
| 切枪下沉 | `260ms` |
| 枪口火焰 | `45ms` |
| 后坐 | 俯仰 `0.35°`/发、偏航抖动 `±0.2°`/发，衰减 `7.5/s` |
| 呼吸 / 行走 | `0.42Hz` / `3.4Hz`（每米相位 `0.55`） |
| 换弹姿态 | 俯角 `0.42 rad`、滚转 `0.30 rad` |
| 倒地姿态 | 俯角 `0.46 rad` |
| 开火间隔 | `rpmToIntervalMs(rpm, mult) = 60000 / (rpm × mult)`（S08 §5）：手枪 `200ms`、步枪 `100ms`、霰弹按公式现算 `60000/70`（不写近似常数） |
| 散布 | 每发 +`0.1°`、上限 `0.25°`、延迟 `350ms` 后按 `6.0°/s` 回落 |

**(c) 特效池与预算**

| 池 | 容量 | 存活/规则 |
|---|---|---|
| 曳光 | `TracerCapacity = 32` | `TracerLocalMs = TracerRemoteMs = 120` |
| 粒子 | `ParticleCapacity = 256` | 点尺寸 `64px`；减少动态模式抖动 ×`0.35` |
| 问号弹 | `EliteBoltCapacity = 24` | 自转 `1.6Hz`、发光缩放 `1.6` |
| 冲锋警戒环 | `ChargeRingCapacity = 12` | 寿命 `1150ms`、未命中阶梯 `16ms` |
| 复用规则 | — | 池满覆盖**最旧**一条并计数；每帧 `Reset()` 只复位游标，帧内不分配 |
| 屏幕反馈 | — | 命中红闪 `150ms`、暗角 `0.12→0.35`、血屏上限 `0.55`、抖动上限 `0.22m`（衰减 `7.5/s`） |

**(d) 曳光共线修正（本步的缺陷修复）**

| 项 | 值 / 定义 |
|---|---|
| v1 缺陷 | 曳光从眼位发出 ⇒ 与视线共线，正面只剩一个点（证据：`playtest-cdp-live`） |
| 修正后起点 | `MuzzleWorld`（与眼位相距 `0.5–0.6m`） |
| 修正后终点 | `playerHit` 的 `hitX` / `hitY` / `hitZ`（权威命中点，`i16` 厘米，S08 §5 / S03 §5.4 的 18B 条目）；未命中时 = 起点 + 视轴方向 × `TracerFallbackLengthM = 30` |
| 共线判据 | 起点与眼位距离 < 0.5m 即判缺陷（测试失败） |
| 数量上限 | 同时存活 ≤ 32；连射 1 秒产生条数 ≤ `1s / 开火间隔 + 1`（手枪 ≤ 6） |
| 触发来源 | 本地开火（枪口火焰 + 曳光）；命中点只信事件，本地不预测命中 |

**(e) 命中反馈三态**

| 态 | 触发条件 | 颜色 | 存活 | 附加表现 |
|---|---|---|---|---|
| 命中 | `playerHit` 且 `HIT_FLAG.killed = 0` 且 `headshot = 0` | `0xFFFFFF` | 140ms | 血屑 6 粒 + 红闪 150ms |
| 击杀 | `sheepKilled`（或 `HIT_FLAG.killed != 0`） | `0xFF4D4D` | 140ms | 屏幕抖动 0.22m + 毛屑 4 粒 |
| 爆头 | `HIT_FLAG.headshot != 0` | `0xFFD24D` | 140ms | 缩放 1.35 + 伤害数字按 `headshotMultiplier = 2.0` 显示 |

## 8. 风险与回滚

| 风险 | 触发信号 | 对策 |
|---|---|---|
| 曳光仍然共线 | 正面开火看不到线段 | 起点必须取 `MuzzleWorld`；测试用"距眼位 ≥ 0.5m"卡死 |
| 特效池溢出导致闪烁 | 密集交火时特效突然消失 | 池满覆盖最旧并把 `OverflowCount` 接到调试输出 |
| 视图模型穿模 | 贴墙时枪体出现在墙里 | 视图模型用独立层（近 0.01 / 远 12），不写深度、不参与场景剔除 |
| 命中反馈缺失 | 只有曳光没有十字 | 反馈只由可靠幂等的事件通道驱动（ADR-009）；缺事件即事件通道问题，不是渲染问题 |
| 空弹匣仍出曳光 | 弹药显示 0 时出现线段 | 开火闸门取 `GateMag = min(optimistic, mag)`（C06）；池层只接受闸门放行的开火 |

**回滚目标**：删除 6 个 `View` 文件与 `effects_pool_test.cs`，回到 `HANDOFF-C08` 状态（开火无视觉表现，模拟与命中判定不受影响）。
