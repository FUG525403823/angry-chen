## 5. 冻结契约

冻结的 v1 对照实现：`packages/client/src/render/sheepModel.ts` 与 `packages/client/src/render/emblem.ts`（只作对照，不修改）。

**(a) 四种羊形尺寸**

| 羊形 | `SheepKind` | 高 m | 半径 m | 羊形缩放 | 羊毛团数 | 额标尺寸 m |
|---|---|---|---|---|---|---|
| 咩咩兵 | `grunt` | 0.9 | 0.50 | `1.00` | 8 | 0.22 |
| 冲撞羊 | `ram` | 1.0 | 0.55 | `1.06` | 12 | 0.22 |
| 问界羊 | `elite` | 1.1 | 0.60 | `1.12` | 12 | 0.22 |
| 羊王 | `king` | 2.4 | 1.60 | `1.60` | 12 | 0.36 |

**(b) 几何参数（羊局部坐标，+Z 为正前方）**

| 项 | 值 / 定义 |
|---|---|
| 躯干高 | `BodyHeightM = 0.62` |
| 羊毛团半径 | `WoolClusterRadiusM = 0.21` |
| 团分布 | x ±`0.62`、z ±`0.42`、y ±`0.20` |
| 团缩放 | `0.86`–`1.14`。网格本身按**羊形**固定种子生成（每形只生成一次、四形共用一份生成器再按形缩放），`EntityId` 抖动落在 `SheepMesh.WoolJitter(kind, entityId)` 的逐实例缩放上，满足「同 id 永远同形」；把种子写进网格会与实例化池互斥（2026-04 修订） |
| 额标挂点 | 头部偏移 y `0.90`、z `0.92`（再乘羊形缩放） |
| 预算 | 顶点 ≤ `512`/形、三角形 ≤ `512`/形；材质 = 4 张羊毛 + 1 张额标 |

**(c) 实例化池**

| 项 | 值 / 定义 |
|---|---|
| 总容量 | `EntityCapacity = 1024`（= 服务端实体上限） |
| 每形容量 | `PerFormCapacity = 256`（4 形 × 256 = 1024） |
| 分配策略 | 构造期一次性预分配；`Reset()` 每帧复位游标；池满即拒绝绘制并 `OverflowCount += 1` |
| 零分配判据 | 连续 3 帧、相同可见集合下实例引用集合恒等，且线程分配字节增量 = `0` |
| 绘制调用 | 每羊形 1 次 `DrawMeshInstanced`，常规 ≤ 4 次；尸体淡出额外 ≤ 1 次 |
| 尸体 | 死亡态保留 `CorpseFadeMs = 1500`，收缩 `0.72`、下沉 `0.16m`、变暗 `0.62` |

**(d) 额标（问界标识，继承 [ADR-003](../../00-共识/ADR/ADR-003-美术素材与问界标识策略.md)）**

| 项 | 值 / 定义 |
|---|---|
| 主色 | `0xE8E8F0` |
| 自发光色（问界羊及其它） | `0x7AD1FF` |
| 自发光色（羊王） | `0xFF8A4C` |
| 基强度 / 跨度 | `EmblemIntensityBase = 0.2`、`EmblemIntensitySpan = 0.8` |
| 强度公式 | `intensity = 0.2 + 0.8 × (1 − clamp01(hpRatio))` |
| 平滑步长 | `EmblemSmoothingPerTick = 0.153518`（= 1 − e^(−0.05/0.3)，写成常量，禁 `exp`） |
| 额标几何与着色 | 程序化网格（菱形描边与外圈写进 `SheepMesh.cs` 的生成器），颜色走**顶点色** + 逐实例材质属性 `_EmissiveTint` / `_EmissiveIntensity`；**不创建 `Texture2D`、不引用任何图片文件**（原「运行时生成 `EmblemTextureSize = 128` 纹理」与零素材断言互斥，已删除） |
| 渲染状态 | `ZWrite Off`、不投影、不透光排序在羊体之后 |

**(e) 剔除与动画映射**

| 项 | 值 / 定义 |
|---|---|
| 视锥 | 6 平面，每帧重建一次；判定前按羊形半径外扩 |
| 距离剔除 | 相机距离 > `CullDistanceM = 90` 直接剔除 |
| 屏幕占比剔除 | 估计占比 < `CullMinScreenRatio = 0.0015`（0.15%）剔除 |
| 剔除预算 | 1024 实体单帧 ≤ `0.3ms` |
| 状态映射 | `SHEEP_STATE`：`0 graze→Idle`、`1 alert→Alert`、`2 chase→Run`、`3 windup→Windup`、`4 charge→Charge`、`5 attack→Attack`、`6 ranged→Ranged`、`7 stagger→Stagger`、`8 dead→Dead`（淡出 1500ms）、`9 kingPhase1→KingIdle`、`10 kingPhase2→KingWalk`、`11 kingPhase3→KingRage`、`12 kingSummoning→Summon` |
| 位域覆盖 | `kindFlags` 的**线上掩码**：`charging = 1<<5 = 32` 时强制 `Charge` 动画；`fading = 1<<6 = 64` 时播放尸体淡出（取值以 `Ac.Net.SnapshotCodec` 为准，`server/src/net/codec.hpp` 的 `flags = (kindFlags >> 2) & 0x3F` 佐证）。原写 `8`/`16` 是把 S03 计划里 `kindFlags` 内的**相对位**（3/4）当成了掩码，会撞上 `rageMode(8)`/`reloading(16)`——狂暴羊被强播 Charge、装填羊被判成尸体（2026-04 审查实算后修订） |

## 8. 风险与回滚

| 风险 | 触发信号 | 对策 |
|---|---|---|
| 1024 实体击穿实例池 | `OverflowCount > 0` | 越界即拒绝绘制并计数；容量按 1024 预分配后不再增长 |
| 额标自发光被合批打断 | 额标颜色不随血量变化 | 用 `MaterialPropertyBlock` / 实例属性而非逐羊材质；测试断言强度曲线而非渲染结果 |
| 剔除把羊王切掉 | 羊王边缘消失 | 平面按羊形半径（羊王 1.6m）外扩后判定 |
| 代码生成网格耗时过长 | 进场加载 > 1s | 每形网格只生成一次并缓存；团抖动种子固定为 `EntityId` |

**回滚目标**：删除 5 个新增文件，回到 `HANDOFF-C07` 状态（C04 视图层退化为灰盒胶囊代理体，模拟不受影响）。
