## 5. 冻结契约

冻结的 v1 对照实现：`packages/client/src/render/arenaArt.ts` 与 `packages/shared/src/config/arena.ts`（只作对照，不修改）。

**(a) 尺寸、网格与生成参数**

| 项 | 值 / 定义 |
|---|---|
| 场地尺寸 | `80m × 80m`（`ArenaHalfSize = 40`） |
| 网格单元 | `GridCellM = 4`；地面 20×20 单元 = 21×21 顶点、800 三角形 |
| 可走区域 | 水平坐标落在 ±40m 内，地面严格平面 `y = 0`（与模拟一致） |
| 围栏 | 高 `FenceHeightM = 3.0`、厚 `FenceThicknessM = 0.5`，沿四边闭合，内表面在 ±40m |
| 谷仓 | AABB `x∈[−4,4]`、`y∈[0,5]`、`z∈[−4,4]`（与 `S06` 的 `barn` 六个值逐值相等） |
| 出生点 | `playerSpawn` 4 个：`(−4.5,7)` / `(−1.5,7)` / `(1.5,7)` / `(4.5,7)` |
| 生成点 | `spawnPoint` 12 个：半径 38m 圆周 12 等分，含 `(0,38)` / `(38,0)` / `(0,−38)` / `(−38,0)` |
| 高度种子 | `ArenaSeed = 1337`，整数哈希（mulberry32 派生，禁超越函数） |
| 远景起伏 | 只允许在 ±40m 以外的环带，幅值 ≤ `OuterRingAmplitudeM = 1.5`；该环带不生成碰撞体 |
| 场地绘制预算 | 顶点 ≤ `4096`、三角形 ≤ `3072`、材质 ≤ `6`、绘制调用 ≤ `8`、1080p 下单帧场地绘制 ≤ 1.0ms（P95） |

**(b) 与模拟的一致性**

| 项 | 值 / 定义 |
|---|---|
| 静态碰撞体 | 只有围栏与谷仓两组 AABB；地面不生成碰撞体（模拟用 `y = 0` 平面） |
| 玩家半径 | `0.4m`（`ENTITY.radiusByKind.player`），围栏内表面按 ±40m 对齐 |
| 生成点用途 | 仅供波次导演取位；12 个点之间最小间距 ≥ `15m`（与 `S09` 的取位约束一致） |
| 不一致判据 | 任何"视觉上能站、模拟里被挡"或反之的区域都算缺陷 |

**(c) 材质参数表**

| 材质 | 用途 | 基色 | 粗糙度 | 金属度 | 贴图 |
|---|---|---|---|---|---|
| grass | 地面 | `0x6F9C52` | 0.92 | 0.00 | 草纹 256px，单元 6m |
| dirt | 谷仓前土场（半径 7.5m 圆） | `0x8A7250` | 0.95 | 0.00 | 土纹 256px，单元 4m |
| fence | 围栏/木构 | `0xA9835A` | 0.85 | 0.00 | 木纹 128px，单元 2.4m |
| barnWall | 谷仓墙 | `0xB45C4A` | 0.80 | 0.00 | 无 |
| barnRoof | 谷仓顶 | `0x59413C` | 0.70 | 0.05 | 无 |
| hay | 干草垛 | `0xD7C273` | 0.90 | 0.00 | 无 |

**(d) 光照与阴影预算**

| 项 | 值 / 定义 |
|---|---|
| 实时光源数 | `1`（方向光；无点光/聚光） |
| 主光 | 旋转 `(50°, −30°, 0°)`，强度 `1.1`，颜色 `0xFFF4E0` |
| 环境光 | 颜色 `0x9DC4E6`，强度 `0.45`；相机背景用同色纯色（不使用天空盒材质文件） |
| 雾 | 线性，近 `42m`、远 `138m`，颜色 `0x9DC4E6` |
| 阴影 | 软阴影，`ShadowDistanceM = 60`，贴图 `2048×2048`，级联 `2` 级（分割 `0.25`） |
| 阴影预算 | 投影渲染器集合 = 围栏 + 谷仓 + 羊 + 玩家，≤ `64` 个渲染器；阴影相关绘制调用 ≤ `4` |
| 相机 | 远裁剪 `138m`（= 雾远点）、FOV `62°`（与视图模型一致） |

## 8. 风险与回滚

| 风险 | 触发信号 | 对策 |
|---|---|---|
| 视觉起伏与模拟地面不一致 | 玩家在起伏带上悬空或穿模 | 起伏只允许在 ±40m 以外的环带且不生成碰撞体；可走区域严格平面 |
| 阴影预算超支 | 帧时间 P95 > 20ms | 按序降级：阴影距离 60→40m、级联 2→1、贴图 2048→1024；仍超则关闭围栏投影 |
| 谷仓/围栏碰撞与模拟漂移 | 玩家能穿过谷仓墙 | 数值只在 §5(a) 定义一次，测试直接断言六值与四面内表面 |
| 代码生成网格耗时过长 | 进场加载 > 1s | 地面用 `CombineMeshes` 合成单网格；远景环带顶点 ≤ 1024 |

**回滚目标**：删除 4 个 `View` 文件与 `arena_mesh_test.cs`，回到 `HANDOFF-C06` 状态（渲染层退化为纯色平面也能跑，模拟不受影响）。
