## 1. 目标
一局对局的全部可听内容都由代码在运行时合成：枪声、羊叫、命中、环境音与 UI 提示音经四条总线混音，冲锋预警与波次/结算以字幕呈现；`client/Tests/audio_test.cs` 在批处理模式下把配方、总线增益、并发上限与字幕时长逐条断言，仓库中不出现任何音频文件。术语取自 [CONTEXT](../../00-共识/CONTEXT.md)，"音频必须程序化生成"的硬约束见 [ADR-003](../../00-共识/ADR/ADR-003-美术素材与问界标识策略.md)。

## 8. 风险与回滚
| 风险 | 触发信号 | 对策 |
|---|---|---|
| 渲染出的波形削波/爆音 | `audio_test` 的峰值断言 > 1.0，或人工听感刺耳 | 每层 `peak` 乘总线增益后做软限幅；把噪声层峰值下调到 ≤ 0.9 |
| 启动预热阻塞主线程 | 首帧耗时 > 50ms（`FrameProfiler` 的 `audio` 段） | 预热改为分帧（每帧最多渲染 4 条配方）；仍超预算则把环境循环改为懒合成 |
| 音源泄漏导致越播越卡 | `Mixer.VoiceCount` 单调上升 | 只允许经 `AudioSource` 池播放，禁用直接 `PlayOneShot`；补齐回收断言 |
| 调度表在实体复用后串音 | 羊叫间隔异常（同一 `EntityId` 连续两次 < 3600ms） | 以 `EntityId` 变化（`lastSeen` 超期）清理记录；补用例 |

回滚目标：HANDOFF-C10。回滚动作 = 删除 `client/Assets/Scripts/Audio/` 与 `client/Tests/audio_test.cs`，并把 `Layers` 的调用点改为空实现；游戏其余功能不受影响（音频静音）。

稳定接口（C12–C15 及后续计划可用，不再改签名）：

- `Mixer`：`SetVolume(MixBus bus, float value)`、`Play(SfxName name, Vector3? position, float gain)`、`VoiceCount`、`AttachListener(Transform)`。

- `Layers`：`HandleEvents(ReadOnlySpan<SimEvent>)`、`NotifyFire(int slot)`、`NotifyReload()`、`Update(float dtMs, in ListenerPose pose, in AudioWorldView world)`。
- `Subtitles`：`Push(SubtitleCue cue, int wave = 0)`、`IReadOnlyList<string> Lines`。
- `AudioTest`（批处理入口）：`Ac.Tests.AudioTest.Run()`，成功时 stdout 末行 `AUDIO-TEST OK recipes=17 asserts=26`。

已验证能力：17 条配方的采样渲染结果与 §5 表一致；四条总线增益可被设置并读回；并发音源上限与最远抢占生效；字幕 3 行/2600ms 去重生效；仓库无音频素材。
