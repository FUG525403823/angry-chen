# C13 设置、持久化与调试面板
> 里程碑：MC13 ｜ 预估：1 人日 ｜ 上游移交物：HANDOFF-C12

## 1. 目标
玩家在客户端内改得的每一项（画质档、音量、鼠标灵敏度、视野、准星颜色、键位）都立刻生效并落盘到 `Application.persistentDataPath/settings.json`，下次启动原样恢复、跨版本可迁移；同时 F3 调试面板用一份固定字段表显示 `playerTick`、ping、丢包、上下行字节、帧时间 P95 与实体数，供性能计划与联调取数。

## 5. 冻结契约
设置键、类型、默认值与范围（键名即 `settings.json` 的字段名，camelCase）：

| 键 | 类型 | 默认值 | 允许范围 | 生效点 |
|---|---|---|---|---|
| `qualityTier` | `int` | `2` | `0` 低 / `1` 中 / `2` 高 | 阴影距离、实例化上限、剔除距离 |
| `masterVolume` | `float` | `0.80` | `0.00 – 1.00` | `AudioSeam.SetVolume(MixBus.Master, v)` |
| `sfxVolume` | `float` | `0.80` | `0.00 – 1.00` | `AudioSeam.SetVolume(MixBus.Sfx, v)` |
| `musicVolume` | `float` | `0.50` | `0.00 – 1.00` | `AudioSeam.SetVolume(MixBus.Music, v)` |
| `sensitivity` | `float` | `1.00` | `0.20 – 3.00` | 输入采样 → 视角增量 |
| `fov` | `float` | `75` | `60 – 100` | 第一人称相机 `fieldOfView` |
| `crosshairColor` | `int` | `0x00FF66` | `0x00FF66 / 0x66E0FF / 0xFFFF66 / 0xFF66CC` | HUD 准星颜色 |
| `colorblindSafe` | `bool` | `false` | `true/false` | HUD 配色切换 |
| `reduceMotion` | `bool` | `false` | `true/false` | 关闭镜头抖动与粒子抖动 |
| `keyBindings` | `string[14]` | 见下 | 每个动作一个非空按键名 | 输入层按键映射 |

默认键位（动作 → 键名，顺序即数组下标，逐条照抄 [C05](C05-输入相机与本地移动预测.md) §5.2 的唯一口径；`sprint` 的 `RightShift` 与 `LeftShift` 同义）：`forward=W`、`back=S`、`left=A`、`right=D`、`sprint=LeftShift`、`jump=Space`、`fire=Mouse0`、`reload=R`、`interact=E`、`rage=F`、`switchWeapon=Q`、`chat=Return`、`settings=O`、`debug=F3`。

持久化格式与路径：

| 项 | 值 |
|---|---|
| 路径 | `Application.persistentDataPath/settings.json`（Windows：`%USERPROFILE%\AppData\LocalLow\AngryChen\angry-chen\settings.json`） |
| 结构 | 顶层对象：`schemaVersion`（`int`，当前 `2`）+ 上表键；不含其它字段 |
| 编码 | UTF-8 无 BOM，缩进 2 空格 |
| 写入 | 写 `settings.json.tmp` → `File.Replace`；每帧最多落盘一次（脏标记 + 帧末 flush） |
| 读取失败 | 解析异常或缺文件 → 使用默认值；原文件重命名为 `settings.bad.json` 后新建 |
| 数值越界 | 逐键 clamp 到上表范围；类型不符用默认值（不整份丢弃） |

版本迁移规则：

| 输入 `schemaVersion` | 动作 | 字段映射 |
|---|---|---|
| 缺失或 `1` | 迁移后立即写回 `schemaVersion = 2` | v1 的 `sensitivity/fov/masterVolume/sfxVolume/colorblindSafe/reduceMotion` 原样搬运；`qualityTier=2`、`musicVolume=0.50`、`crosshairColor=0x00FF66`、`keyBindings=默认表` |
| `2` | 逐键校验 | 同键名直读 |
| `> 2` | 只读不写，内存用默认值，保留文件 | 无（避免降级破坏新版本文件） |

调试面板字段（F3 切换，刷新间隔 250ms，缺失数据源显示 `n/a`）：

| 字段 | 来源 | 格式 | 超阈标记 |
|---|---|---|---|
| `playerTick` | 预测层本地 tick | 整数 | — |
| `serverTick` | 最新快照头 | 整数 | — |
| `ping` | RTT 平滑值（3 次中位） | `%.1f ms` | `> 120ms` |
| `lossPercent` | 快照丢包率（收到/发出） | `%.1f %` | `> 5%` |
| `inboundBytesPerSec` | 传输层 1 秒窗口 | 整数 B/s | `> 40960` |
| `outboundBytesPerSec` | 传输层 1 秒窗口 | 整数 B/s | `> 8192` |
| `frameTimeP95Ms` | 帧时间采样（已冻结签名 `float P95Ms(int stageIndex)`，240 帧环；由 `DebugSample` 注入，未接线显示 `n/a`） | `%.1f ms` | `> 20` |
| `frameTimeMaxMs` | 同一 240 帧环的最大值（由 `DebugSample` 注入，未接线显示 `n/a`） | `%.1f ms` | `> 33` |
| `entityCount` | 视图层活跃实体 | 整数 | — |
| `pooledCount` | 视图层池内实体 | 整数 | — |
| `snapshotRateHz` | 快照率档位 | `%.1f /s` | `< 10` |
| `versionLine` | `VersionInfo.VersionLine` | 原样字符串 | — |

`SettingsStore` 只允许通过 `Get()` 返回不可变快照对象；任何写操作走 `Set(key, value)` / `Reset()` 并触发一次 `Changed` 事件，禁止外部直接改字段。

## 8. 风险与回滚
| 风险 | 触发信号 | 对策 |
|---|---|---|
| 落盘中断导致设置文件损坏 | 启动时出现 `settings.bad.json` | 已是原子替换；把 flush 时机固定到帧末并加一条"写一半被杀"的用例 |
| 迁移丢键或错映射 | 迁移用例失败，或玩家反馈画面/音量回默认 | 迁移表写死在 §5 并由测试逐键断言；未知键只在内存保留一帧后丢弃 |
| 调试面板本身拉高帧时间 | 帧时间采样的 `hud` 段在面板可见时 P95 上升 > 1ms | 面板不可见时不采样；字符串只在刷新点拼接（每 250ms 一次） |
| 键位重绑与输入层冲突 | 同一键被两个动作占用 | `Set` 时先解绑旧占用者并在面板提示；冲突用例进测试 |

回滚目标：HANDOFF-C12。回滚动作 = 删除 `SettingsStore.cs` / `SettingsPanel.cs` / `DebugPanel.cs` 与 `settings_test.cs`，界面回落到 C12 的默认值常量；`settings.json` 保留在磁盘上供下次恢复。
