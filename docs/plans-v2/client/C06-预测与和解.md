## 1. 目标

本步骤结束后，本机陈sir 的移动与弹药显示在丢包、抖动与 RTT 变化下都与服务器权威一致：未确认命令进环形缓冲按 FIFO 重放，权威姿态到达后回滚重放，误差 ≤ 1.0m 走视觉平滑、> 1.0m 硬纠正；弹药开火当帧扣减、同一弹匣周期只降不升、停火 500ms 后与权威静默对齐。跨语言正确性由 `docs/evidence/fixtures/` 的对拍向量逐位验证（ADR-010）。

## 5. 冻结契约

冻结的 v1 对照实现：`packages/client/src/prediction/reconciler.ts` 与 `packages/client/src/prediction/ammoLedger.ts`（只作对照，不修改）。

**(a) 未确认命令缓冲**

| 项 | 值 / 定义 |
|---|---|
| 容量 | `CommandBufferCapacity = 128` 条 |
| 序号 | `ushort`，回绕模 65536；`SeqDiff(a,b) = (a-b)&0xffff`，≥ `32768` 时减 65536（> 0 表示 a 更新） |
| 溢出规则 | 满 128 条时丢弃**最旧**一条并 `OverflowCount += 1` |
| 过期规则 | 只由权威 `lastAckedSeq` 推进（`AckUpTo`）；缓冲不自行过期 |
| 裁剪规则 | 丢弃所有满足 `SeqDiff(seq, slot.Seq) >= 0` 的最旧条目，返回丢弃条数 |
| 分配 | 构造期一次性分配；`Push` / `AckUpTo` 零托管分配 |

**(b) 回滚重放与误差**

| 项 | 值 / 定义 |
|---|---|
| `HardCorrectThresholdM` | `1.0` |
| 误差定义 | `err = sqrt(dx*dx+dy*dy+dz*dz)`，(dx,dy,dz) = 和解前位置 − 重放后位置，全程 `double` |
| 重放顺序 | 落地权威姿态 → `AckUpTo` → 从**最旧到最新**逐条 `localStep(50ms)` |
| 平滑时间常数 | `SmoothingTimeConstantS = 0.12` |
| 每 tick 衰减 | `SmoothingDecayPerTick = 0.65924`（= e^(−0.05/0.12) 的固定步长形式，禁 `exp`，ADR-010） |
| 归零阈值 | `SmoothingEpsilonM = 0.001`，模长小于此值直接归零 |
| 偏移上限 | `SmoothingOffsetCapM = 0.5`，超过即按硬纠正处理 |
| 切换规则 | `err <= 1.0` 且偏移模长 `<= 0.5` → 平滑；否则硬纠正 + `Smoother.Reset()` + `HardCorrectCount += 1` |
| 作用域 | 平滑只作用于渲染变换，绝不写回模拟状态 |

**(c) 弹药本地账**

| 项 | 值 / 定义 |
|---|---|
| 槽位数 | `AmmoSlotCount = 3` |
| 当帧扣弹 | `mag = max(0, serverMag − pending)`，本地开火当帧数字就掉 |
| 只降不升 | 同一弹匣周期内 `mag` 单调不升（`pending` 减少也不回升） |
| 停火自愈 | `pending == 0` 且距最后一次本地开火 ≥ `AmmoIdleHealMs = 500` 时 `mag` 静默回到权威值 |
| 周期重置 | 权威弹匣上升（换弹/补弹）或切换槽位 → `shownMag = optimistic` |
| 开火闸门 | `GateMag = min(optimistic, mag)`；`GateMag == 0` 时本地不产生曳光 |
| 过期判定 | `AckedSeq − AmmoAckGraceSeq > seq`（`AmmoAckGraceSeq = 20`）仍无对应权威下降 → 计入 `RejectedTotal`，且不回弹显示值 |
| 消账顺序 | 权威每下降 1 发消掉**最早**的一条未确认开火（FIFO） |

**(d) 与权威对账的字段来源**

| 对账量 | 来源字段 |
|---|---|
| 本机位置/朝向 | 快照本机实体 `SnapshotEntity.x/y/z/yaw/pitch`，由 C04 投影为 `LocalAuthority { found, x, y, z, yaw, pitch, lastAckedSeq, tick }` |
| 已确认序号 | `LocalAuthority.lastAckedSeq` |
| 弹匣/备弹 | `MatchStatePlayer.mag` / `MatchStatePlayer.reserve` |
| 当前槽位 | `MatchStatePlayer.weapon` |
| 对拍向量 | `docs/evidence/fixtures/*.json`，字段 `seed / configHash / ticks / expected`（ADR-010 §决策 6） |

**(e) 对拍比较口径**

| 项 | 值 / 定义 |
|---|---|
| 浮点比较 | `BitConverter.DoubleToInt64Bits` 逐位相等，不设容差 |
| 失败输出 | fixture 名 + tick + 字段路径 + 两侧位模式，随后断言失败 |
| 覆盖下限 | 至少覆盖静止、直线移动、碰撞、连射命中四类 fixture |

## 8. 风险与回滚

| 风险 | 触发信号 | 对策 |
|---|---|---|
| 跨语言浮点不收敛 | `fixture_predict_test` 首个差异出现在某坐标最低位 | 先核对 ADR-010 子集（禁 `MathF` / `exp` / 超越函数），再确认两侧 fixture 版本一致；两次会话仍不收敛则按 ADR-008 回退到"纯插值不预测" |
| 平滑掩盖真实发散 | `MaxErrorM` 连续 60 帧 > 0.3m | 暴露 `LastErrorM/MaxErrorM`，超阈值打结构化日志并采样 1 帧命令缓冲 |
| 弹药账长期偏离权威 | `RejectedTotal` 增速 > 1/分钟 | 复核 `AmmoAckGraceSeq = 20` 与快照率（10–30Hz）的匹配；必要时把只降不升窗口收敛到一个弹匣周期 |
| 和解拖慢帧时间 | 单帧和解耗时 P95 > 1ms | 缓冲上限 128 已封顶；重放只在收到权威快照时发生 |

**回滚目标**：回到 `HANDOFF-C05` 状态（保留本地预测与输入上行），删除 `CommandBuffer.cs` / `Reconciler.cs` / `AmmoLedger.cs` 与两份测试；或让 `Reconcile` 在 `found == false` 时直接返回，不修正、不平滑。
