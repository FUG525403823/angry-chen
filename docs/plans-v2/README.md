## 1. 每份计划的共同格式

逐节遵守 [计划文档模板](../00-共识/计划文档模板.md) §1 的九段式，另加 v2 双链格式（模板 §5）：

- 头行：`> 里程碑：MS<nn> ｜ 预估：<x> 人日 ｜ 上游移交物：HANDOFF-S<nn-1>`（客户端把 `S` 换成 `C`）
- §2 首行：`**入口条件**：HANDOFF-S<nn-1>`（S01/C01 为 `HANDOFF-S00` / `HANDOFF-C00`）
- §9：`**移交物 ID**：HANDOFF-S<nn>`
- **一次会话可完成**：每份 1–2 人日，任务清单不超过 9 项
- **链接纪律**：只允许链接本仓库**当前已存在**的路径；未来才创建的代码路径一律写成行内代码（否则 `check-docs` 判死链）
- 数值、字段、阈值一律写死；**不允许 TBD/待定**进入 §5 冻结契约
