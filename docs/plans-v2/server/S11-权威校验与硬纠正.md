# S11 权威校验与硬纠正
> 里程碑：MS11 ｜ 预估：1 人日 ｜ 上游移交物：HANDOFF-S10

## 1. 目标

本步结束后，[ServerProcess](../../00-共识/CONTEXT.md) 对每一条上行命令与每一帧姿态都有可执行的信任边界：越界字段被夹取或丢弃、超速位移被硬纠正、无法解释但未越硬上限的位移只记 `ac_pose_suspect_total` 而不处置、命中判定的回退时长 = `min(rttMs/2, 200)` ms，越限返回 `ok=false` 并按当下姿态判定（不回滚），`clamped` 只作诊断计数。判据是 §6 的可执行门槛与一张恶意输入矩阵：任何构造包都不得让进程崩溃，也不得产生"无开火即命中"。校验语义继承 v1 冻结对照实现 `anticheat.ts`、`player.ts` 与 `O01 权威姿态校验与硬纠正语义`。

## 5. 冻结契约

命令与包校验（单位：m、s；`dtMs = 50`）：

| 冻结项 | 常量 / 公式 | 值 |
|---|---|---|
| 单 tick 水平位移上限 | `kHorizontalLimitM = kSprintSpeedMps × dtMs/1000 × kAdvanceTolerance` | 6.3 × 0.05 × 1.15 = **0.36225 m** |
| 垂直速度上限 | `kVerticalLimitMps = kJumpSpeedMps × kAdvanceTolerance` | 4.8 × 1.15 = **5.52 m/s** |
| 位移容差 | `kAdvanceTolerance` | **1.15** |
| 硬纠正阈值 | `(limit + derivedBudget) × kPoseHardCorrectFactor` | 0.36225 × 1.5 = **0.543375 m**（derivedBudget = 0） |
| 命令接受频率 | 每连接命令窗口 | **≤ 30 命令/s**（1s 滑动窗口），超出丢弃并计 `ac_dropped_frames_total` |
| 消息频率与断开 | `kMaxMessagesPerSecond` / `kRateWindowMs` / `kRateStrikesBeforeDisconnect` | **60 / 1000ms / 3**，第 3 次打击发 `Disconnect(reason = 6 rateLimited)` |
| join 失败节流 | `kJoinThrottleFailures` / `kJoinThrottleWindowMs` | **5 / 10000ms** |
| 命令载荷上限 | `kMaxCommandPayloadBytes` | **64 B**；超出整帧丢弃 |
| 单包载荷上限 | [ADR-009](../../00-共识/ADR/ADR-009-UDP传输与协议重构.md) 冻结 | **1200 B**（含包头），超出必分片或丢弃 |

字段范围（一切来自客户端的值都按此夹取，NaN/±Inf 归零）：

| 字段 | 类型 | 合法域 |
|---|---|---|
| `seq` | u16 | 0…65535（回绕） |
| `tick` | u32 | ≥ 0；小于服务器当前 tick 者按过期命令丢弃 |
| `moveX` / `moveY` | double | [-1, 1] |
| `yaw` | double | 取模到 [-π, π] |
| `pitch` | double | [-π/2, π/2] |
| `buttons` | u8 | `& 0xFF`（fire=1/sprint=2/jump=4/reload=8/interact=16/rage=32/switchWeapon=64/ready=128） |
| `switchTo` | u8 | {0, 1, 2}（pistol/rifle/shotgun），其余归 0 |

姿态校验与回滚：

| 冻结项 | 值 / 定义 |
|---|---|
| 处置优先级 | 位置非法 → `Rejected`；超硬上限 → `Corrected`（硬纠正）；派生位移可解释 → `Suspect`（只计数）；否则 `Accept` |
| 派生预算来源 | 仅权威模拟产生（击退、实体分离、静态碰撞外推）；客户端不上行该字段 |
| 回退上限 | `kRewindLimitMs = 200`；`rewind_ms(rttMs) = min(rttMs/2, 200)`（不取整）；越限（`rttMs/2 > 200`）返回 `ok=false` 并按当下姿态判定（不回滚） |
| 姿态历史环 | **20 tick（1s）**，`uint32` tick 为键；取回退姿态统一走 S05 的 `samplePoseAgo`，环内缺失时按当下姿态判定 |
| 回退计数 | `clamped` 仅作诊断：`rttMs/2 > 200` 或环内缺失时计 `ac_rewind_clamped_total`，不改变处置结果 |
| 指标名 | `ac_pose_suspect_total`、`ac_pose_rejected_total`、`ac_hard_correct_total`、`ac_rewind_clamped_total`、`ac_speed_violations_total` |

恶意输入矩阵（12 类，每类 3 变体；矩阵本身是冻结契约，新增类必须先改本表）：

| # | 输入 | 期望行为 |
|---|---|---|
| 1 | 字段为 NaN / +Inf / -Inf | 归零后通过，不崩溃，计 0 打击 |
| 2 | 命令位移超过 0.36225 m/tick 但 ≤ 0.543375 m | `Suspect`，计 `ac_pose_suspect_total`，不改姿态 |
| 3 | 命令位移超过 0.543375 m/tick | 硬纠正回退，计 `ac_hard_correct_total` 与 `ac_speed_violations_total` |
| 4 | 命令速率 31…60/s | 超出部分丢弃，不断开 |
| 5 | 命令速率 > 60/s | 打击 +1；累计 3 次发 `Disconnect(reason = 6 rateLimited)` |
| 6 | 命令载荷 > 64 B | 整帧丢弃，计 `ac_malformed_frames_total` |
| 7 | UDP 载荷 > 1200 B | 丢弃，计 `ac_oversized_frames_total` |
| 8 | 重复 `msgId`（重传） | 幂等：只应用一次，无重复伤害/位移 |
| 9 | 未知 opcode | 丢弃并计 `ac_malformed_frames_total`，不断开 |
| 10 | 越界字段（`moveX = 12`、`pitch = 9`、`switchTo = 7`） | 夹取到 §5 合法域 |
| 11 | 负 `tick` / 未来 `tick` | 丢弃（不重放、不预支） |
| 12 | 请求回退 300ms（`rttMs/2 > 200`） | 返回 `ok=false` 并按当下姿态判定（不回滚），`clamped` 只作诊断计数 |

## 8. 风险与回滚

| 风险 | 触发信号 | 对策 |
|---|---|---|
| 硬纠正误伤合法移动（v1 曾出现） | `ac_hard_correct_total` 在无作弊跑次中 > 5/分钟/人 | 先看派生预算是否为 0：击退/分离/贴墙三类派生位移漏累加；补一路再复跑 |
| 校验进入模拟热路径，破坏对拍 | `fixture` 套件出现首个差异字段 | 校验只允许写在 `security/`，模拟内核不得 include 该目录（用构建目标的依赖方向拦截） |
| 频率窗口误断健康客户端（30Hz 上行撞 60/s 消息上限） | 正常客户端出现 `Disconnect(reason = 6 rateLimited)` | 命令与消息两套窗口分离计数；30Hz 命令只吃命令窗口，可靠重传不计入命令窗口 |
| 越限被当成"回滚到 200ms" | 请求 300ms 回退时仍回滚，隔墙命中被高延迟绕过 | 越限（`rttMs/2 > 200`）必须返回 `ok=false` 并按当下姿态判定；`clamped` 只作诊断计数，测试同时断言越限与边界两侧 |
| 回滚目标 | — | `git revert` 本步提交：删除 `server/src/security/` 与三个测试，服务器退回"只夹取字段、不做姿态处置"的 S10 行为；协议与数据格式无变化 |

## 9. 移交物

**移交物 ID**：HANDOFF-S11

稳定接口：

- `ValidateResult { ok, reason }`：命令校验入口（`validate.cpp`），非法输入只返回结果不抛异常。
- `RateVerdict { Ok, Limited, Disconnect }`：两套滑动窗口的统一裁决类型。
- `PoseVerdict { Accept, Suspect, Corrected, Rejected }`：姿态处置枚举，调用方据此计数。
- `rewind_ms(rttMs) -> uint32`（`rewind.cpp`，= `min(rttMs/2, 200)`）；回退姿态取样复用 S05 的 `samplePoseAgo`，越限返回 `ok=false`（不回滚）。
- 指标：`ac_pose_suspect_total`、`ac_pose_rejected_total`、`ac_hard_correct_total`、`ac_rewind_clamped_total`、`ac_speed_violations_total`。

已验证能力：

- 恶意输入矩阵 36 条 + 20 轮重复跑，进程不崩、计数与断开行为符合 §5。
- 硬纠正边界（0.36225 / 0.543375 m）与回退上限（`min(rttMs/2, 200)`）被测试断言。
- 姿态校验不进入权威模拟路径，跨语言对拍保持逐位一致。
