# P09 美术、音效与"问界"标识

> 里程碑：M8 ｜ 预估：3 人日 ｜ 上游移交物：HANDOFF-H08

## 1. 目标

本步骤结束后，游戏**看起来与听起来像一个成品**：灰盒变成低多边形风格化牧场；每只羊额头都有程序化绘制的「问界」标识，问界羊与羊王的额标随血量下降而更亮（"越残越亮"）；第一人称有手臂与武器动作；开火有枪口火焰、曳光、弹孔、毛屑；音效全部由 WebAudio 合成（枪声、羊叫、命中、冲锋警报、UI）；HUD 与大厅统一视觉主题，并提供色盲安全与减少动态两项可访问性开关。仓库仍然零外部素材。

## 4. 任务清单

- [ ] 写 `emblem.ts`：用 `OffscreenCanvas`（不支持时退回 `document.createElement('canvas')`）绘制 128×128 额标——菱形描边 + 内部问号笔画 + 底衬圆环；导出 `getEmblemTexture()`（单例缓存）与 `emblemIntensity(hpRatio) = 0.2 + 0.8 * (1 - hpRatio)`。
- [ ] 把额标贴到羊头部的独立面片（`PlaneGeometry` 贴在头部前侧，`emissiveMap = emblemTexture`，`emissiveIntensity` 由 §5.2 规则驱动，`depthTest` 保持默认）。
- [ ] 写 `sheepModel.ts`：共享几何体与材质实例；四种羊形通过缩放与配色区分（`grunt` 白+灰、`ram` 深灰+角、`elite` 米白+发光额标、`king` 加体型 1.6 倍与暗红角）；羊毛用 `InstancedMesh`（每只 12 簇，`grunt` 减到 8 簇）以减少 draw call。
- [ ] 写 `viewmodelModel.ts`：手臂用胶囊拼装，武器用长方体拼装（枪管/机匣/弹匣/枪托），独立 `Scene` + 独立相机（避免与主场景的深度冲突），动画用关键帧式插值（位置/旋转/后坐偏移），由状态机驱动（待机呼吸、走动摆动、开火后坐、换弹旋转、切枪下落）。
- [ ] 写 `particles.ts`：预分配 256 个粒子槽，全部 `InstancedMesh`；发射器有并发上限与生命周期；不使用外部贴图，用 `CanvasTexture` 生成圆形软点。
- [ ] 写 `effects.ts`：曳光用细长 `Mesh` + 快速衰减；暗角/血屏/狂暴滤镜用 CSS 层（`#hud` 内的固定定位 div），避免引入后处理管线（性能预算优先）。
- [ ] 写 `arenaArt.ts`：草地/泥土纹理用 `CanvasTexture` 程序化生成（噪声 + 色块），围栏木纹同理；杂物（干草捆、水槽）用基础几何体摆放，且**不参与碰撞**（避免与 P02 的碰撞几何不一致）。
- [ ] 写 `audio/synth.ts` + `sfx.ts`：步枪 = 白噪声 burst（10ms 攻击 + 120ms 衰减）经低通 3kHz + 二次谐波；手枪更短更高；霰弹更低更闷；羊叫 = 两个振荡器（基频 220–320Hz）带颤音与带通；冲锋预警 = 上滑正弦 + 噪声；狂暴怒吼 = 低频锯齿 + 失真。所有音效首次交互后才创建 `AudioContext`（浏览器自动播放策略）。
- [ ] 写 `mixer.ts`：`masterGain` → `sfxGain`/`uiGain`；3D 音效走 `PannerNode`，距离衰减 `refDistance 3 / maxDistance 40`；同时发声上限 24，超出丢弃最远。
- [ ] 写 `settings.ts` + 主题：色盲安全开关切换到色盲友好调色板（避免红绿对立，改用蓝橙对比）；减少动态开关关闭屏幕抖动、暗角脉动与粒子高频抖动；两项都写回 `ac.settings.v1`。
- [ ] HUD 视觉化：准星按当前散布实时扩散；血条受伤残影；怒气条满值脉动；波次条显示 10 段进度；击杀提示右上滚动带爆头标记；Boss 血条居顶。
- [ ] 性能：合并静态几何（围栏/地面/杂物各一 draw call）、开启 `frustumCulled`、羊模型复用几何与材质、粒子池上限 256；把 draw call 数与三角面数显示在调试面板。
- [ ] 测试：`getEmblemTexture()` 返回非空 `CanvasTexture`；`emblemIntensity(1) == 0.2` 且 `emblemIntensity(0) == 1.0` 且单调递增；音效配方在无 `AudioContext` 环境下不抛异常（惰性初始化）；粒子池在 1000 次发射后长度不超过上限。

## 5. 冻结契约

### 5.1 额标规范（冻结，回应 FR-09 与 NFR-10）

| 项 | 值 |
|---|---|
| 载体 | 128×128 `CanvasTexture`，透明背景 |
| 构成 | 菱形外框（描边 6px）+ 居中问号笔画 + 底衬圆环，全部由代码绘制 |
| 贴放 | 羊头部前侧独立面片，尺寸 0.22m × 0.22m（羊王 0.36m × 0.36m） |
| 颜色 | 主色 `#e8e8f0`；自发光色 `#7ad1ff`（羊王改 `#ff8a4c`） |
| 自发光强度 | `emblemIntensity(hpRatio) = 0.2 + 0.8 * (1 - hpRatio)` |
| 平滑 | 强度变化带 0.3 秒时间常数，避免血量骤变时闪烁 |
| 合规 | 不含任何真实商标图形、字体或品牌名称；不使用外部图片 |

### 5.2 HUD 与状态呈现规则（冻结）

| UI 元素 | 数据来源 | 呈现规则 |
|---|---|---|
| 准星扩散 | `WeaponState.spreadDeg`（P06） | 映射 0.5°–5° → 4px–24px |
| 血条/护甲 | 本地玩家 `hpRatio` + 护甲 | 受伤后 0.8 秒残影（第二层红条缓慢追上） |
| 弹药 | `WeaponState.magInSlot[activeSlot]` + `reserveAmmo` | 低于 30% 变黄，空弹匣变红并脉动 |
| 换弹进度 | `reloadEndsAtMs` | 准星下方环形进度 |
| 怒气条 | `rage` | 未满：蓝白；满值：橙色脉动 + 提示键位；狂暴中：倒计时边缘高亮 |
| 波次条 | `MatchState.wave` | 10 段，Boss 波段落标记 |
| 击杀提示 | 事件 2 `sheepKilled` | 右上滚动，爆头加图标，3 秒淡出 |
| 伤害数字 | 事件 1 `playerHit` | 命中点漂浮，爆头更大更亮；**不本地自算** |
| 倒地/救援 | 事件 5/6/7 | 全屏灰化 + 底部救援进度环（仅救援者可见进度） |
| 冲锋预警 | 羊 `state == windup` | 地面红环扩散 + 音效（由 `fx` 流触发，不影响模拟） |

### 5.3 性能预算（冻结，回应 NFR-01）

| 项 | 上限 |
|---|---|
| draw call | ≤ 120（稳态、40 实体） |
| 三角面 | ≤ 180k |
| 粒子并发 | ≤ 256 |
| 同时发声 | ≤ 24 |
| 材质实例 | ≤ 24（共享为主） |
| 帧时间 P95 | ≤ 20ms（1080p、像素比 ≤1.5） |

### 5.4 音频与可访问性（冻结）

| 项 | 值 |
|---|---|
| `AudioContext` 创建时机 | 首次用户交互（点击"进入"按钮）之后 |
| 音量总线 | `masterGain` → `sfxGain`（0.8）/ `uiGain`（0.5） |
| 3D 定位 | `PannerNode`，`refDistance 3`、`maxDistance 40`、`rolloffFactor 1.4` |
| 色盲安全 | 蓝橙对比调色板；不依赖红绿区分敌我与危险度（羊的危险度同时用轮廓粗细与额标亮度表达） |
| 减少动态 | 关闭屏幕抖动、暗角脉动、粒子高频抖动；保留所有影响判定的视觉信息 |
| 字幕 | 关键音效（冲锋预警、波次开始、倒地、胜负）在屏幕上给出文字提示 |

## 8. 风险与回滚

| 风险 | 触发信号 | 对策 |
|---|---|---|
| 程序化美术观感不佳（R-04） | 内部观感清单不通过 | 优先加强轮廓光、雾、配色对比与特效，而非增加多边形；必要时只替换 `materials.ts` 调色板 |
| 粒子与音效拖累帧率 | 帧时间 P95 > 20ms | 粒子并发降到 128、发声上限降到 16；先减特效再加内容 |
| `OffscreenCanvas` 兼容性 | 某些浏览器不支持 | 已设计回退到普通 `canvas`；单测覆盖两条路径 |
| 音效吵闹/刺耳 | 主观反馈 | 所有配方集中在 `sfx.ts`，音量与滤波参数可独立调；提供 sfx 总线音量滑块 |
| 额标在小屏上不可读 | 远距离看不出额标 | 给 `elite`/`king` 的额标加轻微描边光晕，并让额标尺寸随羊形变量（§5.1 已按羊形区分） |

**回滚目标**：`HANDOFF-H08`。移除 `render/{materials,emblem,sheepModel,viewmodelModel,particles,effects,arenaArt}.ts` 与 `audio/**`，退回灰盒渲染（玩法与网络完全不受影响）。
