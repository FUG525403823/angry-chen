# P04 客户端渲染与输入

> 里程碑：M3 ｜ 预估：2 人日 ｜ 上游移交物：HANDOFF-H03

## 1. 目标

本步骤结束后，**在浏览器里可以第一人称走动**：指针锁定后鼠标转视角、WASD 位移、Shift 疾跑、Space 跳跃；场景是程序化生成的 80×80 牧场灰盒（网格地面、围栏、中央谷仓），能看到网络同步过来的羊（灰盒几何体）平滑移动；屏幕上有 HUD 骨架与一个可开关的调试面板（FPS / RTT / tick / 实体数 / 带宽）。客户端此时**还不能开火**——那属于 P06。

## 4. 任务清单

- [x] 建立渲染循环：`requestAnimationFrame` 驱动渲染（60FPS 目标），**与服务器 tick 完全解耦**——渲染只读 `SnapshotView`。
- [x] `scene.ts`：半球光 + 平行光，`fog` 增强纵深与可读性；关闭阴影作为默认（性能预算），保留开关。
- [x] `arena.ts`：按 `config/arena.ts` 数值生成——地面用 `GridHelper` + 单色平面、四周围栏用实例化长方体、中央谷仓用 5 个长方体拼装、12 个生成点用低调的地面圆环标记。
- [x] `entityViews.ts`：对象池（实体 id → view），`kind` 决定几何体；玩家用胶囊 + 朝向指示，羊用球体 + 4 个圆柱腿；创建/销毁只在实体增删时发生，逐帧只更新变换。
- [x] `interpolation.ts`：保留最近 6 个快照，按 `serverTimeMs` 插值到"当前时间 - 100ms"；远端实体位置线性插值 + 角度按最短弧插值；**丢弃 tick 小于已应用 tick 的快照**（ADR-002 的缓解措施之一）。
- [x] `sampler.ts`：每帧采集一次按键状态；以 30Hz 组装 `Command`（`seq` 单调递增、回绕）；按键按下/抬起等"边沿事件"立即补发一帧，避免丢输入。
- [x] `pointerLock.ts`：点击画布申请锁定；`Esc` 释放时显示暂停遮罩；灵敏度按 `0.001 * sens` 缩放；FOV 写入相机。
- [x] `connection.ts`：连接失败/断开显示顶部横幅与具体错误码中文文案（映射 `protocol.ts` 的错误码表）；指数退避重连（1s/2s/4s/8s，上限 8s），重连成功前输入不发送。
- [x] `state.ts`：`SnapshotView` 对渲染层暴露 `getLocalPlayer()`、`forEachVisible(cb)`、`getServerTimeMs()`；**不暴露** `World` 类型（渲染层不得 import `sim`）。
- [x] `hud.ts`：读取 `SnapshotView` 与 `MatchState`，渲染准星、血条/护甲、弹药占位、波次与剩余敌人、怒气条；P06 前弹药与怒气显示占位值。
- [x] `debugPanel.ts`：FPS（1 秒均值 + P95）、RTT（Pong 采样）、当前 tick、可见实体数、最近 60 帧的入站字节/秒。
- [x] `settings/store.ts`：键名 `ac.settings.v1`，字段 `{ sensitivity, fov, masterVolume, colorblindSafe, reduceMotion }`，非法值回落到默认；提供订阅回调供 UI 与渲染层消费。
- [x] 单测：插值在两点间的线性性、角度最短弧、单调丢弃旧快照、采样器 30Hz 节奏与边沿补发、设置存储的非法值回落。
- [x] 手动清单：Edge 打开 → 指针锁定 → 走动 → 看到羊 → 开调试面板 → 断网 5 秒 → 恢复后自动重连。

## 5. 冻结契约

### 5.1 客户端消费边界（架构约束，lint 强制）

```ts
// 允许：client 从 shared 引入
import { PROTOCOL_VERSION } from '@ac/shared';
import { decodeSnapshot } from '@ac/shared/net/codec.ts';
// 禁止：client 直接引入模拟内核内部类型或直接读写世界
import { stepWorld } from '@ac/shared/sim.ts';   // ← 仅 P05 的 prediction/ 目录例外（见 P05 §5）
```

渲染层（`render/**`）只允许接收 `SnapshotView`、`Settings` 与本地输入状态。

### 5.2 `SnapshotView` 公开面（冻结）

```ts
export interface SnapshotView {
  readonly localPlayerId: number;
  getServerTimeMs(): number;
  getAppliedTick(): number;
  getLocalPlayer(): ViewEntity | undefined;         // 本地玩家（P05 起改为预测位置优先）
  forEachVisible(cb: (e: ViewEntity) => void): void; // 已插值，只读
  getStats(): { snapshotsPerSec: number; inboundBytesPerSec: number; rttMs: number };
}
export interface ViewEntity {
  readonly id: number;
  readonly kind: 0 | 1 | 2 | 3;
  readonly pos: { x: number; y: number; z: number };
  readonly yaw: number;
  readonly pitch: number;
  readonly hpRatio: number;
  readonly state: number;
  readonly flags: number;
}
```

### 5.3 渲染与时间参数

| 项 | 值 |
|---|---|
| 插值延迟 | 100ms |
| 快照保留个数 | 6 |
| 像素比上限 | 1.5（移动端/高分屏防止 GPU 过载） |
| 相机 FOV 默认 / 可调范围 | 75° / 60–100 |
| 鼠标灵敏度默认 / 范围 | 1.0 / 0.2–3.0 |
| 渲染帧率目标 | 60 FPS，帧时间 P95 ≤ 20ms |
| 固定 DOM 结构 | `#hud`、`#banner`、`#debug`、`#pause-overlay` 四个根节点，供 P09 的样式复用 |

`ac.settings.v1`：`{ sensitivity: number; fov: number; masterVolume: number; colorblindSafe: boolean; reduceMotion: boolean }`。

### 5.5 实现期澄清（P04）

1. **共享包导入路径**：§5.1 示例中的 `@ac/shared/net/codec.ts` 子路径不可用（`packages/shared/package.json` 只导出 `"."`，见 P03 §5.8）。客户端统一从 `@ac/shared` 根导入，`decode*` 与 `dequantize*` 均由根 `index.ts` 再导出。
2. **插值与反量化的归属**：`net/state.ts` 承担反量化（`dequantize*` 属于 shared，而渲染层被 lint 禁止导入 shared）与"最近 6 帧"关键帧环形缓冲；`render/interpolation.ts` 只保留零依赖的纯数学（`lerp`、`shortestAngleDelta`、`lerpAngle`、`interpolationAlpha`、`findBracket`）。§3 表中"`interpolation.ts` 负责反量化"因此调整为由 `net/state.ts` 承担。
3. **渲染层允许的导入**：`render/**` 允许 `three` 与相对路径的类型导入（如 `import type { ViewEntity } from '../net/state.ts'`，正是 §5.1 允许的 `SnapshotView` 面）；禁止 `@ac/shared`，以及 `**/sim.ts`、`**/world.ts`、`**/rng.ts`、`**/snapshot.ts`、`**/net/connection.ts`。规则位于 `eslint.config.js` 的第二个 `no-restricted-imports` 块，§6 第 7 条已实测拦截。
4. **零逐帧分配**：`SnapshotView` 复用 `ViewEntity` 池与 6 份 typed array 关键帧，`forEachVisible` 以回调逐帧复用同一批只读对象；渲染侧实体 mesh 按 id 池化，逐帧只写 `position`/`rotation`/颜色，消失的实体只置 `visible = false`。
5. **单测环境**：不引入 jsdom。客户端 vitest 项目保持 `node` 环境（`passWithNoTests` 已删除），设置存储通过注入式 `Storage` 接口测试；DOM 与指针锁定行为由无头 Edge 冒烟覆盖。
6. **入场参数**：客户端通过查询串入场——`?room=CODE`（省略则为新房间）、`?name=NAME`、`?server=ws://host:port`，`?debug=1` 打开调试面板（F3 亦可切换）。本地玩家 id 取 `welcome.pid`；指针锁定成功时发送 `ready`（`ReadyRequest.weapon` 置 0）。
7. **几何体简化**：§3 描述的"玩家胶囊 + 羊球体 + 4 条圆柱腿"改为更省的盒体组合——玩家：盒体 + 球形头；羊：盒体 + 盒体头，**额头带「问界」徽标**（深色底板 + 自发光核心，作为头部子节点随朝向旋转；P09 替换为正式徽标部件）。羊的 `state & 1` 暂作"发疯"配色判据（真实语义在 P07 定义）。
8. **HUD 与面板范围**：P04 的 HUD 为文字骨架（房间码 · 阶段 · 连接状态 · HP + 一行统计），准星/血条/怒气条的最终布局留给 P09；`#banner` 承载事件、错误码与断线文案；调试面板 250ms 刷新一次。
9. **重连退避**：实现取 2s、4s、8s……上限 15s（§4 写的是 1s/2s/4s/8s 上限 8s），起点更保守，避免刚断开就高频重试。
10. **像素比与帧统计**：像素比 `min(devicePixelRatio, 1.5)`；逐帧同时记录 RAF 间隔（P95，对应"帧时间 P95"）与 `render()` 自身耗时（P95），后者用于定位渲染浪费。

## 8. 风险与回滚

| 风险 | 触发信号 | 对策 |
|---|---|---|
| 帧率不达标 | FPS < 58 | 关闭阴影、像素比降到 1.0、羊用 `InstancedMesh`（P09 会进一步优化） |
| 插值引入可感知延迟 | 手动观感"跟不上" | 100ms 是 NFR-03 的预算值；若必须下调，先确认抖动吸收是否足够（ADR-002 第 4 条） |
| 指针锁定在 Edge 上的行为差异 | 锁定失败或 Esc 后无法再锁定 | 每次申请前先 `document.exitPointerLock()`；失败时显示"点击继续"遮罩 |
| 逐帧分配造成 GC 抖动 | 帧时间 P99 突刺 | 复用 `Vec3`、避免在渲染循环里创建闭包与数组；`forEachVisible` 用回调而非生成数组 |
| Vite HMR 与 WebSocket 连接状态冲突 | 改代码后连接重复创建 | 连接对象在模块级单例管理，HMR 时显式 `dispose` |
| 打包后整体被 tree-shake | 构建产物远小于 500 kB 且不含 three | `main.ts` 必须显式调用 `boot()`（实现期曾因只导出未调用导致产物 4.5 kB），并把构建体积作为回归信号 |
| 无头环境量不到 FPS | `#debug` 读数缺失 | 以单测覆盖插值与采样，性能读数留待真实 GPU 目视；P09 引入性能预算回归手段 |
| 渲染层类型导入的方向性 | `render/**` 出现值导入 `net/state.ts` 形成环 | 该导入仅允许 type-only；P05 建 `prediction/` 时重新评估依赖方向 |
| 构建体积警告 | `vite build` 提示 chunk > 500 kB | 已知并接受（three 本体 ~560 kB / gzip ~144 kB）；如需拆分在 P09 处理 |


**回滚目标**：`HANDOFF-H03`（服务器 + 协议）。客户端退回 P01 的"显示协议版本号"页面，服务器不受影响。
