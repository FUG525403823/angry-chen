# P04 客户端渲染与输入

> 里程碑：M3 ｜ 预估：2 人日 ｜ 上游移交物：HANDOFF-H03

## 1. 目标

本步骤结束后，**在浏览器里可以第一人称走动**：指针锁定后鼠标转视角、WASD 位移、Shift 疾跑、Space 跳跃；场景是程序化生成的 80×80 牧场灰盒（网格地面、围栏、中央谷仓），能看到网络同步过来的羊（灰盒几何体）平滑移动；屏幕上有 HUD 骨架与一个可开关的调试面板（FPS / RTT / tick / 实体数 / 带宽）。客户端此时**还不能开火**——那属于 P06。

## 4. 任务清单

- [ ] 建立渲染循环：`requestAnimationFrame` 驱动渲染（60FPS 目标），**与服务器 tick 完全解耦**——渲染只读 `SnapshotView`。
- [ ] `scene.ts`：半球光 + 平行光，`fog` 增强纵深与可读性；关闭阴影作为默认（性能预算），保留开关。
- [ ] `arena.ts`：按 `config/arena.ts` 数值生成——地面用 `GridHelper` + 单色平面、四周围栏用实例化长方体、中央谷仓用 5 个长方体拼装、12 个生成点用低调的地面圆环标记。
- [ ] `entityViews.ts`：对象池（实体 id → view），`kind` 决定几何体；玩家用胶囊 + 朝向指示，羊用球体 + 4 个圆柱腿；创建/销毁只在实体增删时发生，逐帧只更新变换。
- [ ] `interpolation.ts`：保留最近 6 个快照，按 `serverTimeMs` 插值到"当前时间 - 100ms"；远端实体位置线性插值 + 角度按最短弧插值；**丢弃 tick 小于已应用 tick 的快照**（ADR-002 的缓解措施之一）。
- [ ] `sampler.ts`：每帧采集一次按键状态；以 30Hz 组装 `Command`（`seq` 单调递增、回绕）；按键按下/抬起等"边沿事件"立即补发一帧，避免丢输入。
- [ ] `pointerLock.ts`：点击画布申请锁定；`Esc` 释放时显示暂停遮罩；灵敏度按 `0.001 * sens` 缩放；FOV 写入相机。
- [ ] `connection.ts`：连接失败/断开显示顶部横幅与具体错误码中文文案（映射 `protocol.ts` 的错误码表）；指数退避重连（1s/2s/4s/8s，上限 8s），重连成功前输入不发送。
- [ ] `state.ts`：`SnapshotView` 对渲染层暴露 `getLocalPlayer()`、`forEachVisible(cb)`、`getServerTimeMs()`；**不暴露** `World` 类型（渲染层不得 import `sim`）。
- [ ] `hud.ts`：读取 `SnapshotView` 与 `MatchState`，渲染准星、血条/护甲、弹药占位、波次与剩余敌人、怒气条；P06 前弹药与怒气显示占位值。
- [ ] `debugPanel.ts`：FPS（1 秒均值 + P95）、RTT（Pong 采样）、当前 tick、可见实体数、最近 60 帧的入站字节/秒。
- [ ] `settings/store.ts`：键名 `ac.settings.v1`，字段 `{ sensitivity, fov, masterVolume, colorblindSafe, reduceMotion }`，非法值回落到默认；提供订阅回调供 UI 与渲染层消费。
- [ ] 单测：插值在两点间的线性性、角度最短弧、单调丢弃旧快照、采样器 30Hz 节奏与边沿补发、设置存储的非法值回落。
- [ ] 手动清单：Edge 打开 → 指针锁定 → 走动 → 看到羊 → 开调试面板 → 断网 5 秒 → 恢复后自动重连。

## 5. 冻结契约

### 5.1 客户端消费边界（架构约束，lint 强制）

```ts
// 允许：client 从 shared 引入
import { PROTOCOL_VERSION } from '@ac/shared';
import { decodeSnapshot } from '@ac/shared/net/codec.ts';
// 禁止：client 直接引入模拟内核内部类型或直接读写世界
import { stepWorld } from '@ac/shared/sim.ts';   // ← 仅 P05 的 prediction/ 目录例外（见 P05 §5）
```

渲染层（`render/**`）只允许接收 `SnapshotView`、`Settings` 与本地输入状态。

### 5.2 `SnapshotView` 公开面（冻结）

```ts
export interface SnapshotView {
  readonly localPlayerId: number;
  getServerTimeMs(): number;
  getAppliedTick(): number;
  getLocalPlayer(): ViewEntity | undefined;         // 本地玩家（P05 起改为预测位置优先）
  forEachVisible(cb: (e: ViewEntity) => void): void; // 已插值，只读
  getStats(): { snapshotsPerSec: number; inboundBytesPerSec: number; rttMs: number };
}
export interface ViewEntity {
  readonly id: number;
  readonly kind: 0 | 1 | 2 | 3;
  readonly pos: { x: number; y: number; z: number };
  readonly yaw: number;
  readonly pitch: number;
  readonly hpRatio: number;
  readonly state: number;
  readonly flags: number;
}
```

### 5.3 渲染与时间参数

| 项 | 值 |
|---|---|
| 插值延迟 | 100ms |
| 快照保留个数 | 6 |
| 像素比上限 | 1.5（移动端/高分屏防止 GPU 过载） |
| 相机 FOV 默认 / 可调范围 | 75° / 60–100 |
| 鼠标灵敏度默认 / 范围 | 1.0 / 0.2–3.0 |
| 渲染帧率目标 | 60 FPS，帧时间 P95 ≤ 20ms |
| 固定 DOM 结构 | `#hud`、`#banner`、`#debug`、`#pause-overlay` 四个根节点，供 P09 的样式复用 |

### 5.4 本地存储键（冻结）

`ac.settings.v1`：`{ sensitivity: number; fov: number; masterVolume: number; colorblindSafe: boolean; reduceMotion: boolean }`。

## 7. DoD（验收标准）

1. `pnpm check` 全绿；`pnpm --filter @ac/client test` 有 ≥ 8 个用例。
2. §6 第 3、4 条手动验收通过：浏览器内第一人称可走动、可见远端玩家与羊平滑移动。
3. 帧时间 P95 ≤ 20ms（调试面板读数），FPS ≥ 58。
4. 旧快照被单调丢弃：注入乱序快照的单元测试通过，画面不出现"倒退"。
5. 客户端源码中不存在对 `sim.ts` 的导入（`prediction/` 目录在 P05 才建立，本步应完全为空）。
6. 设置持久化：刷新页面后灵敏度/FOV 保持不变；写入非法值后回落默认且不抛异常。
7. 零外部素材：本步所有几何体与材质均为代码生成，无加载任何外部 URL（网络面板可见）。

## 8. 风险与回滚

| 风险 | 触发信号 | 对策 |
|---|---|---|
| 帧率不达标 | FPS < 58 | 关闭阴影、像素比降到 1.0、羊用 `InstancedMesh`（P09 会进一步优化） |
| 插值引入可感知延迟 | 手动观感"跟不上" | 100ms 是 NFR-03 的预算值；若必须下调，先确认抖动吸收是否足够（ADR-002 第 4 条） |
| 指针锁定在 Edge 上的行为差异 | 锁定失败或 Esc 后无法再锁定 | 每次申请前先 `document.exitPointerLock()`；失败时显示"点击继续"遮罩 |
| 逐帧分配造成 GC 抖动 | 帧时间 P99 突刺 | 复用 `Vec3`、避免在渲染循环里创建闭包与数组；`forEachVisible` 用回调而非生成数组 |
| Vite HMR 与 WebSocket 连接状态冲突 | 改代码后连接重复创建 | 连接对象在模块级单例管理，HMR 时显式 `dispose` |

**回滚目标**：`HANDOFF-H03`（服务器 + 协议）。客户端退回 P01 的"显示协议版本号"页面，服务器不受影响。
