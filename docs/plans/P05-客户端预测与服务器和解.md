# P05 客户端预测与服务器和解

> 里程碑：M4 ｜ 预估：2.5 人日 ｜ 上游移交物：HANDOFF-H04

## 1. 目标

本步骤结束后，**移动零延迟感**：按下 W 立刻动，不受 RTT 影响；同时服务器始终说了算——一旦权威位置与本地预测不一致，客户端回滚重放未确认命令，并用视觉偏移平滑吸收误差（超过 1m 才硬纠正）。服务器侧新增**回滚补偿命中判定**：射手开火时，服务器把被瞄准目标回退到射手看到它的那个时刻再求交，且回滚上限 200ms。远端实体继续平滑，抖动被插值吸收。

## 4. 任务清单

- [ ] 抽出 `sim/localStep.ts`：把"应用命令 → 移动积分 → 与静态几何碰撞"从 `stepWorld` 中提取为可复用函数，`stepWorld` 内部调用它，客户端预测也调用它（**同一份代码**，禁止复制）。
- [ ] `commandBuffer.ts`：`push(cmd)`、`ackUpTo(seq)`、`pending()`；回绕安全比较（`seqDiff(a,b)` 处理 uint16 回绕）；容量满时丢弃最旧并记一次 `overflowCount`。
- [ ] `predictor.ts`：维护本地玩家预测状态（pos/vel/yaw/onGround）；每渲染帧以固定 50ms 子步推进（累积器模式，最多补 5 步，保证与服务器步长一致）。
- [ ] `reconciler.ts`：收到快照时——
  1. 取权威本地玩家状态作为起点；
  2. `ackUpTo(snapshot.lastAckedSeq)` 丢弃已确认命令；
  3. 对剩余命令按序重放，得到新的预测状态；
  4. 计算误差 `err = |predicted - serverAtAck|`；
  5. `err ≤ 1m` → 把误差作为视觉偏移交给 `errorSmoother`（不改变模拟位置）；`err > 1m` → 硬纠正并记一次 `hardCorrectCount`。
- [ ] `errorSmoother.ts`：偏移按帧衰减 `offset *= exp(-dt / 0.12)`，偏移量阈值 0.001m 后归零；偏移只作用于渲染变换，不写回模拟状态。
- [ ] `history.ts`：环形缓冲 `20 × { tick, players: [{id, pos, yaw, pitch}] }`；`sampleAgo(ms)` 在相邻两槽间线性插值；`ms` 被夹取到 `[0, 200]`（`rewindLimit`）。
- [ ] `raycast.ts`：`rayVsCapsule(origin, dir, capsule, maxDist)`、`rayVsAabb`，返回 `{ hit, t, point, normal }`；纯函数、无分配（结果写入调用方传入对象）。
- [ ] `room.ts`：每 tick 末写入历史；处理开火命令时，用射手的 `RTT/2` 作为回滚时长（夹取到 200ms），对候选目标用历史姿态求交，命中后才是"既成事实"。
- [ ] `anticheat.ts`：校验每条命令的位移是否超过 `maxSpeed * dt * 1.15`、垂直速度是否超过跳跃上限、位置是否落在场地与障碍之外；违规时**以服务器结果覆盖客户端**并把该 tick 的权威位置强制下发，累计 `speedViolations` 指标。
- [ ] 客户端在 `?debug=1` 面板增加：预测误差（当前/最大）、硬纠正次数、待确认命令数。
- [ ] 测试：
  - [ ] 和解收敛：给定人为注入 ±0.5m 误差的权威快照，重放后误差 ≤ 量化步长（1cm）。
  - [ ] 重放确定性：同命令序列在 `localStep` 与服务器 `stepWorld` 下的本地玩家轨迹逐位一致。
  - [ ] 回滚采样：`sampleAgo(100)` 在已知轨迹上等于中间插值值；`sampleAgo(500)` 被夹到 200ms。
  - [ ] 校验规则：构造 3 倍速命令，服务器拒绝并纠正。
  - [ ] 延迟注入集成测试：用内存适配器注入 150ms 延迟 + 3% 丢包，跑 600 tick，断言硬纠正次数 ≤ 2、无"隔墙命中"（射线命中记录的目标位置与射手可见位置差 ≤ 0.5m）。

## 5. 冻结契约

### 5.1 预测范围（只预测这些，多一分都不做）

| 预测 | 不预测 | 理由 |
|---|---|---|
| 本地玩家的移动与碰撞 | 任何羊的移动 | 羊由服务器 AI 驱动，客户端插值即可；预测羊会引入"鬼畜回溯" |
| 武器的视觉后坐与换弹进度条 | 伤害与命中结果 | 命中是权威事实，客户端只做乐观表现（P06 落地） |
| 指针视角（本地立即生效） | 投射物轨迹 | 投射物在服务器生成后广播 |

### 5.2 允许越界导入的唯一位置

P04 §5.1 禁止客户端 import `sim`。**唯一例外**是 `packages/client/src/prediction/**`，且只允许导入：`@ac/shared/sim/localStep.ts`、`@ac/shared/math.ts`、`@ac/shared/command.ts`。禁止在该目录外导入 `stepWorld` 或 `World`。lint 白名单按目录配置。

### 5.3 和解参数（冻结）

| 参数 | 值 | 含义 |
|---|---|---|
| 硬纠正阈值 | 1.0 m | 超过则直接采用权威位置 |
| 视觉偏移衰减时间常数 | 0.12 s | `offset *= exp(-dt/0.12)` |
| 待确认命令缓冲 | 128 条 | 超出丢弃最旧并计数 |
| 预测子步长 | 50ms | 必须等于 `SERVER_TICK_MS` |
| 单帧最大子步数 | 5 | 防止长帧后追帧雪崩 |

### 5.4 回滚补偿（服务器，冻结）

| 参数 | 值 |
|---|---|
| 历史环长度 | 20 槽（1 秒 @20Hz） |
| 回滚时长 | `clamp(rttMs / 2, 0, 200)` |
| 采样方式 | 相邻槽线性插值 |
| 超出上限 | 不回滚，按当下姿态判定（并记 `rewindClampedCount`） |
| 命中判定的几何 | 玩家 = 胶囊（半径 0.4，高 1.7）；羊 = 胶囊（半径 0.5，高 0.9），头部子段用于爆头判定 |

### 5.5 服务器姿态校验阈值（冻结）

| 规则 | 阈值 |
|---|---|
| 水平位移/命令 | `≤ maxSpeed(6.3) * 0.05 * 1.15` 米 |
| 垂直速度 | `≤ 4.8 * 1.15` m/s |
| 位置合法性 | 必须落在场地内且不在障碍 AABB 内 |
| 违规处理 | 权威值覆盖 + `speedViolations` 计数，不直接断线（断线阈值由 P10 的限流规则统一管理） |

## 7. DoD（验收标准）

1. `pnpm check` 全绿。
2. 预测与权威使用同一份移动代码：`grep -rn "stepWorld" packages/client/src` 的结果只出现在 `prediction/`；`localStep` 被服务器与客户端共同调用（代码审查确认）。
3. §6 第 4 条通过：150ms 延迟下手动操作无可感知滞后，60 秒内硬纠正 ≤ 2 次。
4. 回滚命中生效且有上界：`ac_rewind_clamped_total` 在注入 400ms 延迟时增长（说明夹取生效），且不存在回滚超过 200ms 的命中记录。
5. 速度作弊被纠正：注入 3 倍速命令的测试中，服务器位置未被带偏，`ac_speed_violations_total` 增长。
6. 渲染层不写回模拟状态：`errorSmoother` 的输出只用于 `entityViews` 的变换（代码审查 + 单测断言模拟位置未被修改）。

## 8. 风险与回滚

| 风险 | 触发信号 | 对策 |
|---|---|---|
| 和解过于频繁导致"橡皮筋" | 调试面板的硬纠正次数持续增长 | 提高硬纠正阈值前先查根因（步长不一致/命令丢包）；可临时把阈值提到 1.5m 并记录 ADR |
| 预测与权威步长不一致 | 静止时位置缓慢漂移 | 强制子步 50ms，且 `localStep` 与 `stepWorld` 共用实现（本步的核心约束） |
| 回滚造成"隔墙击杀"观感 | 玩家反馈"他明明在墙后" | 校验规则：命中要求射手与目标之间无障碍（用同一 AABB 几何做遮挡检测） |
| 历史环内存开销 | 20 槽 × 4 玩家小对象，实测可忽略 | 若实体数增大，改为紧凑 `Float32Array` 槽位 |
| 客户端预测只对本地玩家做，但本地玩家 id 未知 | 首帧预测本地玩家失败 | 以 `Welcome.pid` 为准；`Welcome` 未到达前不预测、不发送命令 |

**回滚目标**：`HANDOFF-H04`。移除 `client/src/prediction/**` 与 `errorSmoother.ts`，`SnapshotView.getLocalPlayer()` 退回纯插值结果；服务器移除历史环与回滚判定（命中退回"当下姿态"）。二者独立可回滚。
