## 固定任务

1. 不听额外口头说明，打开本地客户端，在大厅作为主机选择“启用远征”，准备开始。
2. 第一局首卡选“精准猎手·标记”。按界面指引进入设施防守区域，尝试瞄头及连续射击同一只羊、使用治疗脉冲，完成首节点。阅读奖励条件，自行选择下一卡。
3. 第二局首卡选“破阵冲锋·打断”。尝试六米内攻击、打断与换位，观察远距离攻击代价，再完成首节点。
4. 至少一局继续走完三节点（有效防守合计九分钟，含奖励约十分钟）；可记录失败后重开，不要求无失败首通。

不得通过测试后门缩时、无敌、直接授卡或伪造目标成功。Classic仍默认，原玩法可在大厅不启用远征直接进入。
