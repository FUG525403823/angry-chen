# 灵敏度、准星与重复换弹修复

## 验证边界

用户明确禁止启动 Unity/团结、构建或运行客户端。本次只做代码修改、静态检查和 Node 仓库门禁；客户端回归仅补源码，未执行。不宣称客户端编译通过、游戏内交互通过或用户症状已经实机复现。

## 修改

- 默认 O 打开设置；解锁鼠标后可点击左上设置按钮。面板打开时屏蔽游戏输入，关闭同帧及鼠标未释放时继续屏蔽，保持网络更新。
- 灵敏度统一使用 SettingsDefaults：0.20–5.00，默认 1.00，滑条步进 0.05。修改即时应用，恢复默认刷新输入和表现层。
- 准星支持现有四色、大小倍率、粗细、中心间距、静态/动态，并共用实战绘制方法预览。粗细与间距默认 2 像素，大小默认 1，默认动态。
- 配置升级 v3；旧版补默认，未来版本不覆盖。保存失败可见；非拖动时最多每秒尝试保存一次，正常退出追加保存。设置打开时使用 GUILayout，未承诺模态 UI 零分配。
- HUD 分行显示“弹匣 x / 容量”“备弹 y”，明确换弹进度、弹匣已满、备弹耗尽；无权威弹药时显示等待同步。

## 静态证据与修复

1. 原 GameLoop.FillSample 每帧对同一份缓存 MatchState 调用 LocalWeapon.SyncAuthority，且后者只降不升。本地换弹刚补满又被旧弹匣压低，备弹已扣除；后续权威补弹也不能向上纠正。现改为仅新 MatchState 到达时同步一次，接受权威增减，HUD 和本地开火共享 LocalWeapon 数据。身份变化/重连清理状态。
2. 服务端 room.cpp 使用 floorUnits(reloadRemainingMs, 10.0) 发送 10ms 单位。AmmoCounter 原除以 10，现乘以 10。新权威包重设本地换弹截止时间，缓存帧不重复重设，进度随本地时间推进。
3. AmmoLedger 未确认射击记录原未区分槽位；现按槽位记账、消费和计算，避免换枪错误扣账。

MatchState 没有弹药对应的命令确认序号/精确时间戳，因此当前同步仍为粗粒度权威纠正，不是精确回放。高延迟下弹药或换弹进度可能在新包到达时校正；本次不修改协议、无限补弹或武器平衡。

## 用户实机验收

1. 大厅按 O 或点设置；对局按 O。拖动灵敏度后关闭，确认手感变化，恢复默认有效。等一秒正常退出再启动，确认保留设置。
2. 分别调整颜色、大小、粗细、间距，切换动态；预览与实战一致。色盲安全会覆盖所选颜色，目标/受伤颜色反馈仍保留。
3. 打开面板时按移动键、R、鼠标左键，不应移动/开火/换弹/转视角；关闭按钮不能导致开枪。测试 Esc、聊天和失焦恢复。
4. 每种武器有备弹时连续完成至少三轮：射击/打空 → R → 等完成 → 再射击 → R。检查只扣实际装填量，换弹提示按时结束。
5. 检查满弹匣、0 备弹、少量备弹只能部分装填、换枪中断、波间补给、重连后的弹药显示。
6. 若仍异常，请记录武器、按 R 前后弹匣/备弹数字、是否显示换弹中、等待秒数、是否换枪/重连，最好附短视频。这能区分剩余网络纠正问题和输入/显示问题。
