# CONTEXT —— 统一语言（术语表）

本文件是《愤怒的陈sir vs 发疯的羊群》项目的**唯一术语来源**。代码标识符、协议字段、文档正文、测试用例名一律使用本表左列术语；禁止同义词混用（例如不得把"波次"写成"关卡"、把"命令"写成"输入包"）。

## 1. 玩法域术语

| 术语 | 标识符 | 定义 |
|---|---|---|
| 陈sir | `ChenSir` | 玩家角色。第一人称视角，持有枪械，拥有「怒气」。本项目不做 NPC 陈sir。 |
| 玩家 | `Player` | 一个已加入房间并处于对局中的真人。一个玩家控制一个陈sir。 |
| 羊 | `Sheep` | 敌方单位的总称。所有羊都有一个「额标」。 |
| 羊形 | `SheepKind` | 羊的种类枚举：`grunt`（咩咩兵）、`ram`（冲撞羊）、`elite`（问界羊）、`king`（羊王）。 |
| 发疯 | `frenzy` | 羊的攻击性来源（疯草）。它不是状态，只是背景设定，不产生字段。 |
| 额标 | `emblem` | 绘制在羊额头的「问界」风格标识。纯视觉，不参与模拟判定。 |
| 问界羊 | `elite` | 精英羊形。额标自发光，能发射「问号弹」。 |
| 羊王 | `king` | Boss 羊形。多阶段。 |
| 问号弹 | `questionBolt` | 问界羊发射的远程投射物。 |
| 怒气 | `rage` | 陈sir 的资源条，由击杀累积，满值后手动激活「狂暴」。 |
| 狂暴 | `rageMode` | 怒气满值并激活后的限时增益状态（伤害/射速/移速提升）。 |
| 倒地 | `downed` | 玩家生命归零后的可救援状态。 |
| 救援 | `revive` | 队友按住交互键 3 秒使倒地玩家复起的行为。 |
| 波次 | `wave` | 一轮敌人生成与清剿。波次内不再分批补怪，除非波次预算未耗尽。 |
| 波间 | `intermission` | 两个波次之间的备战窗口，默认 20 秒，可被全员准备跳过。 |
| 波次导演 | `WaveDirector` | 决定每波生成什么、生成多少、在哪生成的纯逻辑模块。 |
| 预算 | `budget` | 波次的生成点数。每个羊形有价格，导演在预算内组队。 |
| 场地 | `arena` | 对局发生的地图。MVP 只有一张：80m×80m 的牧场。 |
| 生成点 | `spawnPoint` | 场地上允许生成敌人的位置列表。 |
| 出生点 | `playerSpawn` | 玩家的复活位置列表。 |
| 备战 | `loadout` | 玩家在对局开始前或波间选择的武器。 |

## 2. 系统域术语

| 术语 | 标识符 | 定义 |
|---|---|---|
| 世界 | `World` | 一局对局的全部可变状态。纯数据，不含渲染对象。 |
| 实体 | `Entity` | 世界中的一个可模拟对象（玩家/羊/投射物/掉落物）。由 `EntityId` 标识。 |
| 实体标识 | `EntityId` | `uint16`，在单个世界内唯一。复用由空闲表管理。 |
| 命令 | `Command` | 客户端上行的一份意图（移动轴、视角、开火、换弹…）。**不是**结果。 |
| 事件 | `Event` | 服务器权威判定的既成事实（命中、击杀、波次开始、救援完成…）。 |
| 步进 | `stepWorld` | 把一个世界推进一个固定 tick 的纯函数入口。 |
| 快照 | `Snapshot` | 某一 tick 的世界的可渲染可传输投影。是**投影**，不是世界本身。 |
| 基线 | `baseline` | 差分快照所依赖的、服务器确认客户端已持有的那个 tick。 |
| tick | `tick` | 服务器固定步长单位，50ms。真实时间不是 tick。 |
| 模拟内核 | `@ac/shared` 的 `sim` 模块 | 不依赖 three/DOM/Node 的纯逻辑模拟。 |
| 视图 | `SnapshotView` | 客户端持有的只读快照集合与插值结果。客户端**只**能读它。 |
| 预测 | `prediction` | 客户端在本地提前步进自己的命令。只预测本机玩家，不预测羊。 |
| 和解 | `reconciliation` | 收到权威快照后回滚重放未确认命令，修正本地预测位置的过程。 |
| 回滚 | `rewind` | 服务器为命中判定把目标姿态回退到玩家开火时刻的行为。 |
| 回滚上限 | `rewindLimit` | 允许回滚的最大时长，200ms。超过则不回滚，按当下姿态判定。 |
| 传送 | `Transport` | 一个缝：`send` / `onMessage` / `close`。生产适配器是 WebSocket，测试适配器是内存队列。 |
| 会话 | `Session` | 服务器侧一个连接的全部状态。 |
| 房间 | `Room` | 一个独立对局的容器。由房间码寻址。 |
| 房间码 | `roomCode` | 4 位大写字符，用于加入房间。排除易混淆字符（0/O/1/I/L）。 |
| 权威 | `authoritative` | 只有服务器产生既定事实。客户端的一切状态都是推测。 |
| 宽限期 | `graceperiod` | 玩家断线后保留其位置与名额的时长，30 秒。 |
| 对局状态机 | `MatchPhase` | `lobby → loading → playing → intermission → ended`。 |
| 质量门 | `pnpm check` | typecheck + lint + test + 文档链校验。任何提交必须通过。 |

## 3. 硬约束词汇（出现即表示不可违反）

| 词 | 含义 |
|---|---|
| **纯净性** | `@ac/shared` 不得 import `three`、DOM API、`node:*`、`Math.random`、`Date.now`。 |
| **同源模拟** | 服务器权威、客户端预测、无头机器人必须调用**同一个** `stepWorld`，不得各自实现一份。 |
| **零外部素材** | 仓库不含任何第三方模型/贴图/音频二进制。所有视听内容在运行时程序化生成。 |
| **可擦除语法** | 只使用可被类型剥离的 TypeScript 语法（禁 `enum`、禁参数属性、禁 `namespace`）。 |
| **线性文档链** | 计划文档 P01→P10 顺序执行，每份的入口条件等于上一份的移交物。 |
