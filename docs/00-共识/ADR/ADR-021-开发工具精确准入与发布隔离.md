# ADR-021 开发工具精确准入与发布隔离

- 状态：已接受（P0有限依赖边界；不代表P0整体通过）

保留外部工作添加的Codely Bridge 1.0.87与TJGenerators 1.0.27，但仅作为有执行权限的开发工具准入；不扩大为`cn.*`白名单，不修改供应商源码、原始manifest或lock。准入必须同时符合记录的版本、manifest引用、lock来源与依赖闭包、官方归档SHA256以及包文件树SHA256；Generators额外52项Unity生成meta只允许记录中逐路径逐哈希的可选内容。新版本或同版本内容变化必须重新审查。

不选择“asmdef标记Editor即相信不会发布”：Generators存在无平台限制的Runtime程序集，真实旧发布实物已检出TJGenerators.Runtime.dll。发布使用一次性项目投影去除这两个工具依赖并重新解析运行时闭包，构建后仍必须对实际stage执行独立audit-release（供应商内容哈希及编译程序集/插件名称）；原始项目与供应商包保持不变。不直接删除发布DLL来伪造安全构建，也不将旧stage审计失败视为新投影构建结果。

包内无LICENSE不等于无使用权；既有官方条款与安装指引为本地开发使用提供上下文，但不被解释为允许再分发工具或第三方原生库。动态编译、进程启动、联网及源码上传属于已披露开发工具风险，本P0不承诺完整安全认证，不无限扩张为所有工具的全面审计。素材零外部二进制规则不因本决策而改变。
