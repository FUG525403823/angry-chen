# ADR-003 美术素材与"问界"标识策略

- 状态：已接受（M0 前）；**v2 继续有效**——Unity 客户端同样受「零外部素材」约束
- 生效范围：`@ac/client` 的 `render/*`、`audio/*`，以及所有美术相关的计划文档

## 背景

1. 需求：羊的额头要有「问界」标志。
2. 约束：本仓库**零外部素材**——不下载模型、贴图、音频；不引入美术资源的二进制文件；保证离线可运行。
3. 风险：真实汽车品牌标识属于注册商标，把品牌 Logo 直接放进可分发代码有法律与合规风险，也违反"零外部素材"。

## 决策

1. **全部视听内容程序化生成**：
   - 模型 = three.js 基础几何体的组合与实例化（`InstancedMesh`、低多边形拼装）。
   - 贴图 = 运行时 `CanvasTexture` 绘制（含额标）。
   - 音效 = WebAudio 合成（噪声 burst + 滤波 + 包络、调制振荡器）。
   - 界面图标 = 内联 SVG 或 Canvas 绘制。
2. **「问界」额标以原创风格化标识承载"问界"观感**：由菱形外框 + 问号笔画构成，程序化绘制在 `CanvasTexture` 上，贴在羊额头四边面片的 `emissive` 通道上。
3. **不使用任何真实商标的图形、字体、名称拼写**：不出现品牌中文全称的商标图样，不使用品牌官方字体。
4. **标识是纯视觉**：不参与模拟、不影响判定，不在 `@ac/shared` 中出现任何额标相关字段。
5. **发光等级语义**（冻结）：`emissiveIntensity = 0.2 + 0.8 * (1 - hp/maxHp)`，问界羊与羊王在血量下降时额标更亮，作为"越残血越危险"的可读信号。

## 备选方案与被否决理由

| 方案 | 否决理由 |
|---|---|
| 使用真实品牌 Logo 图片 | 商标风险 + 违反零外部素材 |
| 引入外部免费模型/贴图包 | 违反零外部素材；且需要许可管理 |
| 用文字 `"问界"` 直接渲染 | 字体依赖与商标问题；远看不可读，且截图分享风险更高 |
| 完全不画额标 | 直接违背核心需求 |

## 后果

- 正面：仓库可离线构建、体积极小、无许可纠纷；风格统一为"低多边形 + 高饱和"。
- 负面：观感上限低于手绘素材。为弥补，把预算投入到**可读性**（轮廓光、雾、配色、受击反馈、屏幕特效）而非多边形数量。
- 若项目负责人确认要更接近真实车标的观感，须先改写本 ADR，并明确该构建仅供内部娱乐、不分发。

## 已确认为开放问题

"问界"是否确实指汽车品牌风格的标识（而非"问号"）。默认按后者之外的风格化标识实现；若确认是"问号"，只需替换 `emblem` 绘制函数，协议与模拟零改动。
