# ADR-022 P1远征切片与协议3

状态：按已批准增强计划P1范围执行。继承ADR-009/010的传输、量化、固定步长与Classic规则；仅本节明确部分升版。选择独立RunState和可靠请求而非扩塞Classic升级与八位Command，避免破坏Classic fixtures、玩家身份和输入契约。

## 范围与模块接口

一个80m牧场/谷仓布局（既有碰撞不改）、三次同目标遭遇、一个治疗脉冲、六卡。目标是设施区域防守，不宣称敌人已有寻路攻击建筑：中心(12,0)、半径6m，存活羊在圈内每只每秒扣设施2HP；设施初始1000HP，每节点重置。玩家需要在圈内且站立非idle才能推进净化，至少一人即推进（不按人数提速）；需180秒有效净化，240秒超时失败。三节点+奖励约10分钟，离开圈不能白等胜利。设施归零优先于同tick净化完成。波次导演复用生成原语及预算，每25秒有限压力段，节点1/2/3预算8/12/16按人数比例；不走Classic十波结束/升级点，也不调用运行时负载补羊。

远征模块持RunState（runId、node、目标、结果、个人候选/截止/已选），对外begin/request/tick/read；调用者pid从已验证Session推导，绝不读请求自报pid。构筑模块封装卡与触发预算，Entity末尾追加默认禁用BuildState；公共接口enableBuild/resetBuild/selectCard/calculateHitModifier/onHit/onKill/updateBuild/pulse。遭遇模块持目标与进度，提供begin/tick/read。Classic房间走原路径。使用五态MatchPhase，远征奖励为Intermission内部状态。所有新局清构筑，重连不重置。

六卡稳定ID及数值定义见[内容文本](../../expedition-p1-content.txt)。1头部命中标记目标3秒（本击先计算、后标记），后续直接命中已标目标乘1.5，未标身体乘0.85；2头部返1发，500ms冷却且不超弹匣，身体乘0.85；3静止满1秒头部乘1.75，移动时乘0.8；4六米内命中羊进入500ms Stagger，同射手/目标2秒冷却，远处乘0.8；5六米内击杀回血8，1秒冷却，远处乘0.8；6六米内击杀填满当前弹匣并取消换弹，2秒冷却，远处乘0.8。额外倍率依ID顺序；只有直接伤害，无衍生递归。返弹/补弹不改备弹；瞬时治疗不复活。治疗范围为实体中心三维距离≤8m，满血施放仍成功消耗冷却；工具冷却使用战斗模拟时钟，安全阶段暂停冷却，网络显示换算为当前房间时钟加剩余冷却。流派名“破阵冲锋”指近距打断进攻，不承诺P1新增位移冲刺。既有移动不变，仍需P1双端逐tick对拍覆盖相同布局/命令。

个人三选一：1/4为无前置启动卡，2/3需1、5/6需4；候选无重复、不含已持有，卡最多一次；不足三个时使用0=补给选项（不算机制卡）。第一次固定同时提供两启动卡及补给，不强制选流派；后续从合法池独立奖励RNG抽取，无可用卡仍可补给。每局一次重抽；跳过/超时提供25HP存活治疗及30备弹，不自动选卡。30秒安全窗口，全连接玩家完成可提前继续，断线不阻塞；截止用房间50ms时钟，不依赖只在战斗步进的world.timeMs。初次开战前一次奖励，两节点后各一次奖励；第三节点成功结算。

## 协议3与历史兼容

生产双端显式使用3，旧生产客户端明确Disconnect(versionMismatch)，不跨版混房。历史codec默认常量2及旧fixture保持，generic codec允许历史2和当前3；这仅用于离线历史回归，生产Runtime/UdpTransport入口严格3。既有载荷除Hello外不改。Hello版本2仍12B；版本3严格20B，旧nonce u32+token ASCII8后加contentVersion u32=1及contentHash u32（内容文件原始UTF8字节的FNV1a32）。不符拒绝且不分配房间身份；SHA256同时用于来源审计，FNV不是安全签名。新消息只在3合法。

type13 ExpeditionRequest，可靠，载荷固定18B：runId u32、offerId u32、requestId u32、op u8、choiceId u8、reserved u32(恒0)。op=1启用远征（仅大厅host，run/offer=0）；2选择；3跳过；4重抽；5工具；6返回Classic（仅大厅host）；7再来一局（仅Ended host）。选卡op2允许choice0补给、1..6卡；工具choice1；其他choice恒0。runId除大厅配置外必须匹配；选择/跳过/重抽offer必须匹配且属于本人窗口；工具offer=0且仅Playing可用。requestId非零、单玩家单run单调，缓存最近请求及结果；相同ID相同内容重发返回原结果，不重复扣资源；同ID不同内容或更旧ID拒绝。失败也回执，不乐观改本地构筑。错run的迟到请求必须在当前run水位/缓存之前拒绝，不占当前run的requestId空间；未完成工具请求独立保留结果，即使更新请求先到也能恢复原结果。永久离房清该成员回执及排队动作，token重连则保留，避免EntityId复用继承旧身份水位。

type14 ExpeditionState，可靠单播完整恢复，固定载荷上界256B，不分片、不依赖瞬时事件。字段顺序：schema u8=1，mode u8(0 Classic/1 Expedition)，runId u32，revision u32，clockMs u32，stage u8(0 idle/1 reward/2 combat/3 ended)，node u8(0..3)，result u8(0 none/1 success/2 facilityDestroyed/3 timeout/4 allDowned)，layoutId u8=1，objectiveId u8=1，toolId u8=1，objectiveHp u16，progressMs u32，combatLeftMs u32，rewardDeadlineMs u32，localPid u16，offerId u32，offerCount u8(0或3)，choices 3xu8（无offer全0），resolved u8(0/1)，rerollsLeft u8(0/1)，lastRequestId u32，lastResult u8(0 none/1 accepted/2 wrongMode/3 wrongRun/4 wrongPhase/5 staleOffer/6 invalidChoice/7 duplicateConflict/8 unavailable/9 notHost)，playerCount u8(0..4)，然后每人pid u16、cardMask u8(仅bits0..5)、toolReadyAtMs u32、triggerCount u32。count/localPid/ID/枚举/保留位/精确长度一律校验。State按1Hz与请求/阶段变化立即发；重连立即完整发送。单包上界小于256，不绕现有分片可靠类型丢失缺口。

## P1 损伤网络的输入时效与快照自愈（2026-11-04实测修订）

真实2人delay50/loss5/乱序轮出现864/818次BaselineMismatch、解码/坏包/分片错误为0，丢失一帧基线可令后续delta连续拒绝到2秒周期全量；AppliedTick冻结又让原2tick输入窗口拒绝移动/开火，形成雪崩。保留历史delta编码、Classic与未知基线拒绝，不改为接受损坏delta，不重设计ACK基线环，也不每帧强制全量。

仅远征Playing采用12tick（600ms）有界迟到输入受理窗口。推导来自批准的100ms单向网络档：每向乱序额外100+25ms，因此最坏上下行225+225ms；合法10/15Hz快照档最大相位100ms，加30Hz输入采样33.34ms，合计583.34ms向50ms tick上取整为600ms。20Hz仅需550ms，但窗口必须覆盖合法降档。丢包/无限调度停顿不具有有限最坏界，超过600ms仍拒绝；这不是以网络差为由无限放宽。Classic及其他阶段仍原2tick，未来tick、序号去重、速度校验及命中rewind的200ms硬上限保持，不把600ms当成可回溯命中时长，也不令客户端伪造clientTick。

对已验证身份/endpoint且合法解码的远征Playing超窗旧输入，仍拒绝执行，但可提示下一复制发送独立全量；每客户端至少4tick间隔，独立hint序号含16bit回绕且拒绝重复/乱序，不消费命令dedup。合法延迟输入不请求全量；未来tick不请求全量。pending全量只在UDP成功发送后清除，编码/背压/发送失败保留。真实UDP边界与原场景必须重跑，并测带宽，不能只凭单测宣称损伤网络门通过。

## 定长内存账

P1不采用外置指针/堆sidecar隐藏World真实占用：BuildState随Entity末尾追加80B对齐空间，Entity由976→1056B，World由1028520→1110440B（增加81920B）。旧`sizeof(World)<1MiB`是S05一次预分配卫生断言，历史S08/S09已随真实字段扩容，不是RSS增长斜率硬门；本次以精确1110440B取代，而非任意放宽至2MiB。实体1024/事件256/4玩家容量、无热路分配、G7 RSS增长<1MB/min及帧/带宽等原硬预算完全不变；实际RSS和性能验收仍需记录。默认禁用状态也占该空间，这项代价公开，不通过侧移分配伪造通过。

## 测试与代价

测试缝限定为批准计划公共模块接口、双端codec/生产UDP与GameLoop。新协议fixture独立版本目录/文件，不批量更新旧golden；每卡纵向红绿与原场景复测，Classic fixtures及既有硬预算继续运行。协议入口旧版拒绝与坏内容真实UDP回归；全状态恢复包括目标、构筑、候选、截止及动作回执。P1不用完整P4矩阵替代有限切片退出，但缺测仍非PASS。人类打法差异判定单独保留。
