# 运维手册

> 本文件按链条分工：**客户端章节由客户端链维护**（本文件当前只含客户端内容）；服务端章节由 S01–S15 链维护，合并前不要在此重复描述服务端拓扑。

## 客户端

### 构建（一条命令出发布包）

```
# 仓库根目录执行；AC_UNITY 指向团结引擎/Unity 编辑器可执行文件
pwsh -File client/build.ps1 -Backend auto     # auto = 有 win64_il2cpp 变体就用 IL2CPP，否则 Mono 兜底
```

- 退出码：`0` 出包成功；`1` 构建失败（日志 `client/Logs/build.log`）；`2` 环境缺失（`AC_UNITY` 未指向可用编辑器）。
- 成功时最后一行固定为 `BUILD OK <归档名>`。
- **后端规则**：IL2CPP（x64）是发布通道；本机团结引擎只装了 `win64_player_*_mono` 变体、没有 `win64_il2cpp`，因此 `-Backend auto` 实际走 **Mono**，并在构建日志第一行与 `manifest.json` 里标注 `backend=Mono`。拿到带 IL2CPP 模块的编辑器后不需要改命令，`auto` 会自动切回 IL2CPP。
- 脚本会先把 `Assets/Scripts/Core/BuildInfo.g.cs` 覆盖成当前 commit 与构建时间（扫描时写入，运行期改不了）。

### 产物与校验

产物在 `client/Build/Windows64/`（不入库）：

| 文件 | 说明 |
|---|---|
| `ac-client-<semver>+<sha7>-win64.zip` | 发布包，自包含 `angry-chen.exe` + `angry-chen_Data/`；已排除 Unity 标注的 `*_BurstDebugInformation_DoNotShip` |
| `<归档名>.sha256` | `<hash>  <归档名>` |
| `latest.txt` | 单行：`<归档名> <sha256>` |
| `manifest.json` | 归档名、sha256、semver、commit、proto、backend、构建时间、版本行 |

校验（分发前必做）：

```
$line = Get-Content client/Build/Windows64/latest.txt
$name, $hash = $line -split ' '
(Get-FileHash (Join-Path 'client/Build/Windows64' $name) -Algorithm SHA256).Hash.ToLowerInvariant() -eq $hash   # 必须 True
```

### 分发

把 `ac-client-<semver>+<sha7>-win64.zip` 整个解压到一个空目录后运行 `angry-chen.exe`（Mono 包依赖同目录的 `MonoBleedingEdge/` 与 `TuanjiePlayer.dll`，不要只拷 exe）。玩家侧不需要装引擎。

### 日志位置与轮转

- 运行期目录：`%USERPROFILE%\AppData\LocalLow\<公司名>\angry-chen\logs\`。
- 单文件：`client-<yyyyMMdd>.log`，**JSON 单行**，每行都带 `version` 字段（等于构建时的版本行）。
- 单个文件超过 **8 MiB** 轮转，保留 **5** 份备份（`.1` … `.5`，最旧的先删）。
- 未捕获异常另写 `crash-<yyyyMMdd-HHmmss>.log`：首行版本行，后接最多 200 行堆栈。

### 版本核对（联调必做）

客户端唯一版本行：`ac-client 0.1.0+<sha7> proto=1`（来源 `Core/VersionInfo.cs`）；服务器唯一版本行：`ac_server 0.1.0 protocol=1 tick=50ms`。

规则：`proto` 必须等于 `protocol`（不等则按 ADR-009 以 `Disconnect(reason=1 versionMismatch)` 拒绝连接）；`MAJOR.MINOR` 必须相等；客户端的 `+<sha7>` 与服务器的 `tick=50ms` **不参与**判定，但两侧版本行都必须写进验收报告。

### 常见故障

| 现象 | 原因 | 处理 |
|---|---|---|
| `build.ps1` 退出 2 | `AC_UNITY` 未指向可用编辑器 | 设置环境变量或先导入 `HKCU:\Environment` 的 `AC_UNITY` |
| 构建日志出现 `backend=Mono2x` | 缺 `win64_il2cpp` 变体 | 属预期兜底；要发 IL2CPP 包就在 Hub 补装该编辑器的 IL2CPP 模块 |
| `build.ps1`/其它 `.ps1` 报"字符串缺少终止符" | 脚本是**无 BOM 的 UTF-8 但含中文**，Windows PowerShell 5.1 按 ANSI 解码把中文字节解出引号 | 存成 **带 BOM 的 UTF-8**（本仓库的 `build.ps1`/`frame-bench.ps1` 已加 BOM，新增脚本请照做） |
| 玩家侧日志为空 | 没连上或没到写日志的阶段 | 先看 `crash-*.log`，再看当天 `client-<日期>.log` 的 `version` 字段确认跑的是哪个包 |
| 反复重连 | 版本行不等或网络抖动 | 比对两侧版本行的 `proto`/`MAJOR.MINOR`，再看日志里的重连原因 |
